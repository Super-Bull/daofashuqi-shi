# 视角：新农人 / 三农（种植养殖/农产品/乡村文旅）

> 适用：种地养殖的、做农产品电商的、返乡创业的、搞乡村文旅的。三农的账有个特点：**生产端谁都努力，销售端一塌糊涂**——农民不是穷在种地，是穷在卖货。

## 一、五层长相（新农人眼里的道法术器）

| 层 | 这拨人的真实长相 | 典型误区 |
|---|---|---|
| 道 | 你要种好地还是卖好货：生产思维 vs 商品思维——定位决定赚不赚钱 | 只会种不会卖，好货烂在地里 |
| 法 | 单件毛利、损耗率、账期、库存——非标品的账比种地难 | 只看产量不看损耗和售价，丰收≠增收 |
| 术 | 渠道：批发、电商、社区团购、文旅采摘 vs 只有一个收购商 | 一个收购商压价，你没有任何议价能力 |
| 器 | 冷链、分拣、分级、溯源、直播设备 vs 只有地和力气 | 好东西没有分级没有包装，卖不出价 |
| 势 | 乡村振兴政策、直播电商、溯源品牌化、AI 对农业渗透低 | 政策是东风，但你得有帆——没渠道接不住 |

## 二、典型死法映射

- **道层死法 · 情怀承包** → 为"回乡情怀"包下山头，账没算过，三年赔光
- **法层死法 · 丰收灾** → 大丰收→价格崩→损耗高→白干一年，循环十年
- **术层死法 · 渠道单一** → 全靠一个收购商，他倒你倒，他压价你只能接受
- **器层死法 · 非标困局** → 好货混着卖，没有分级没有标准，客户不敢付高价
- **势层死法 · 政策依赖** → 等补贴、等项目，不建自己的渠道——政策一变全归零

## 三、行业困局（这行到底卡在哪）

丰收灾（增产不增收，越丰越贱）、渠道单一（被贩子压价）、非标品难定价（好货卖不出好价）、补贴依赖（离开补贴就不会算账）。三农的账有个特点：生产端谁都努力，销售端一塌糊涂——穷在卖货，不穷在种地。

## 四、大众困局（这拨人常见的误会）

- "种得好就卖得好"——错。种得好只是入场券，卖得好才赚钱。
- "等收购商上门就行"——错。渠道单一，只能任人压价。
- "跟风种热门作物"——错。等你上市，价格早崩了。

## 五、势从哪来

1. **溯源与品牌化**：消费者为"谁种的、怎么种的"付溢价——分级和故事是涨价工具。
2. **直播与社区团购**：绕开收购商直达消费者——这是新农人最大的势。
3. **订单农业与预售**：先收钱后种植，把价格风险转移出去。
4. **农文旅结合**：采摘、研学、体验——一产接三产，利润率翻倍。

## 六、归因分类

| 类型 | 真相 |
|---|---|
| 种植型 | 有产品缺渠道——最该补的是卖货，不是技术 |
| 电商型 | 懂流量缺供应链——爆单了发不出货更致命 |
| 文旅型 | 有资源缺内容——采摘园死在"除了摘没别的可玩" |
| 服务型（农机/农资/托管） | 卖服务最稳——但要注意账期 |

## 七、专属漏洞（诊断重点看）

1. **非标品怎么卖上价**：分级、分级、分级——大小、品相、规格分开卖，混着卖永远最低价。
2. **预售和订单农业**：先收定金再种，把"丰收灾"变成"确定性收入"。
3. **渠道组合**：批发保底+电商赚溢价+文旅吃体验——别把身家押一个渠道。
4. **政府补贴口径**：补贴是锦上添花不是商业模式——靠补贴活的一定先死。
5. **直播带货的坑**：坑位费、以次充好反噬、退货率——农产品退货是双杀（运费+损耗）。

## 九、数据纪律

- **能用（定性）**：农产品电商持续增长、溯源品牌受青睐、订单农业推广（普遍共识）。
