# 视角：外贸 / 跨境人（SOHO/工厂转型/平台运营）

> 适用：做外贸 B2B、跨境电商、货代、SOHO 外贸人。外贸的坑有个特点：**全在看不见的地方**——账期、汇率、平台规则、客户归属。单看着都旺，账一算全是泪。

## 一、五层长相（外贸人眼里的道法术器）

| 层 | 这拨人的真实长相 | 典型误区 |
|---|---|---|
| 道 | 你卖货还是卖服务：贸易商赚差价 vs 供应商赚制造——定位决定利润天花板 | 既是贸易商又像供应商，客户不知道你到底是谁 |
| 法 | 单件毛利、账期、汇率、库存、退换货——外贸死于账期不死于没单 | 只看订单金额，不算资金占用和汇兑损失 |
| 术 | 客户从哪来：平台、展会、独立站、开发信——阿里国际站烧钱陷阱 | 把平台当唯一渠道，客户在平台手里不在你手里 |
| 器 | 供应链掌控度、客户资产归属、文档体系 vs 只有一台电脑 | 客户资料在平台后台，一封邮件就能被平台规则掐死 |
| 势 | 关税与地缘、汇率波动、AI 翻译拉平沟通门槛、B2B 转 B2C | 还以为"会英语"是护城河——AI 已经把它拉平了 |

## 二、典型死法映射

- **道层死法 · 定位模糊** → 贸易商不像贸易商，供应商不像供应商，利润薄到没缓冲
- **法层死法 · 账期拖死** → 货出去了，钱分三次回来，现金流断在第三批
- **术层死法 · 平台依赖** → 国际站年费+烧钱，询盘越来越贵，停投就归零
- **器层死法 · 单客户依赖** → 一个大客户占 80% 营收，他倒你倒
- **势层死法 · 语言护城河幻觉** → 靠"我会英语"吃饭，客户已经用 AI 直接和工厂对话了

## 三、势从哪来

1. **AI 翻译普及**：语言门槛消失，老外贸最大的比较优势在贬值——价值要向"供应链整合+服务"迁移。
2. **地缘与关税**：订单在转移，早转移的在吃肉，晚转移的在清库存。
3. **B2B 转 B2C/小 B**：跨境平台让"小单快反"成立，贸易商的资金门槛在降。
4. **独立站与私域**：把客户从平台搬到自己的地盘，是这个行业唯一在增值的器。

## 四、归因分类

| 类型 | 真相 |
|---|---|
| 工厂转型型 | 有产品缺渠道——最该补的是客户从哪来 |
| SOHO 型 | 轻但脆——没供应链接单发不出货，先解决器 |
| 平台运营型 | 懂规则缺资产——客户是平台的，你是租客 |
| 服务型（货代/验厂/认证） | 卖服务最稳——但要防大客户自建团队替代 |

## 五、专属漏洞（诊断重点看）

1. **客户资产归属**：客户邮箱、WhatsApp、订单记录在哪？在平台后台=你随时可能被清零。
2. **账期与锁汇**：平均回款天数、汇率敞口——这两项不做管理，利润是假的。
3. **独立站 vs 平台**：平台买流量，独立站攒资产。预算再紧也要开始攒。
4. **AI 的正确用法**：用 AI 做开发信、多语言跟进、市场调研——省下的是语言成本，不是找客户成本。
5. **从"接单"到"选客户"**：挑客户比接客户难但值钱——劣质客户吃掉你全部利润还占满产能。

## 六、金句池（沙龙直接用）

- "外贸死于账期，不死于没单。"
- "客户在平台手里，你就是在给平台打工。"
- "AI 把英语拉平了，老外贸的语言护城河没了。"
- "一个大客户占八成营收，你这老板当的是他的部门。"
- "接单是本事，挑单是境界——劣质客户吃掉你全部利润。"

## 七、数据纪律

- **能用（定性）**：外贸订单向新兴市场转移、跨境电商门槛降低、汇兑波动常态化（普遍共识）。
- **禁用**：编"某平台询盘成本 X""行业平均毛利 X%"——品类、模式差异极大，编了就是误导定价。

## 八、转诊线

- 报关、退税、信保、海外合规 → 找专业代理和税务，别用 AI 的话报税
- 海外建仓/本土公司（≥30 万投入）→ 转 business-inference-core
- 从接单转产品化/品牌化 → 可转 `perspective-manufacturing` 视角重拆
- 长期压款、焦虑失眠 → 先接住情绪照常拆，多半死在"钱在客户和平台的账上"
