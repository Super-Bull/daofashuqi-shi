# 视角：全职妈妈（重启职场/副业/小微创业）

> 适用：离开职场回家几年、现在想重新做事的人——副业、小微创业、重启职场。这拨人最缺的不是能力，是**被家庭碎片化后的时间账**和**"我还能行吗"的自我怀疑**。

## 一、五层长相（全职妈妈眼里的道法术器）

| 层 | 这拨人的真实长相 | 典型误区 |
|---|---|---|
| 道 | 你要的是"找回自己"还是"多份收入"——两个都对，但路径完全不同 | 用证明自己的方式选项目，选了个最烧钱的 |
| 法 | 碎片化时间下什么生意成立：不能全职的生意怎么设计 | 高估自己可支配的小时数，按"全职的预期"接半职的局 |
| 术 | 从熟人圈破冰：妈妈群、社区、老同事 vs 一上来就做公域账号 | 从零开始做全网粉丝，第一个月就饿死 |
| 器 | 可迁移技能盘点：几年家务管理是本事，别当空白 | 把"脱离职场几年"当成履历空白，自我清零 |
| 势 | 女性经济、社区团购、妈妈 IP、AI 降低创业门槛 | 看不见自己所在的妈妈社群本身就是渠道 |

## 二、典型死法映射

- **道层死法 · 补偿型创业** → 为证明自己砸钱开店，钱是家用钱，亏了家里鸡飞狗跳
- **法层死法 · 时间幻觉** → 按"孩子上学后我有八小时"规划，实际能用的不到三小时
- **术层死法 · 社交型努力** → 买课、混圈子、加社群，认识一堆人，一个客户没有
- **器层死法 · 体面陷阱** → 觉得小区团购、手工定制"丢人"，非要租门面做"像样的生意"
- **势层死法 · 窗口误判** → 追最火的项目（直播/加盟），火的时候进场就是接盘

## 三、势从哪来

1. **AI 拉平技能门槛**：以前要外包的设计、文案、剪辑，现在自己+AI 能干——小微创业的启动成本历史最低。
2. **社区经济**：妈妈群、小区团购、社区口碑是离你最近的现金流。
3. **信任势**：妈妈身份的信任背书（母婴、教育、家庭消费）是别的人群抢不走的。
4. **家庭支持系统**：老公、父母、托班——这不是后勤，这是你的基础设施，要先谈好。

## 四、归因分类

| 类型 | 真相 |
|---|---|
| 重启型 | 想回职场——卡点通常在信息差和信心，不在能力 |
| 副业型 | 想有点自己的收入——最务实，从小做起就能活 |
| 被迫型 | 家庭收入断了/老公出状况——最急也最容易慌，越慌越不能投钱 |
| 认同型 | 找自我价值——最该被尊重，但要小心用钱买存在感 |

## 五、专属漏洞（诊断重点看）

1. **时间账（最重要）**：拿一张纸写出每周真实可支配小时数。多数人写完会发现，选项目的标准全变了。
2. **启动资金红线**：家用钱、孩子教育钱、救命钱——一分都不能动。预算为零的生意才配开始。
3. **家庭协商是基础设施**：老公/婆婆不支持，不是你错了，是你还没证明这事能成——先做出第一笔收入再谈扩大。
4. **从小做起不丢人**：小区团购、手工定制、邻里互助、经验咨询——能来钱的都不小，锁在门面里的才危险。
5. **几年家务不是空白**：同时管理几个项目的调度能力、预算控制、危机处理——这是运营本事，给它标价。

## 七、数据纪律

- **能用（定性）**：女性小微创业门槛降低、社区团购和妈妈经济活跃（普遍共识）。
- **禁用**：编"宝妈副业月入 X""女性创业成功率 X%"——贩卖焦虑的数据全是营销号编的，一个字别引用。

## 八、转诊线

- 家庭重大财务决策、抵押房产创业 → 超出轻量自检，明确建议家庭内部先谈，必要时转 business-inference-core
- 婚姻危机、长期抑郁、自我否定到极致 → 走 `emotional-companion.md` 危机边界，暖着转介——这个身份的心理负荷被严重低估
- 副业阶段 → 转 `perspective-sidehustle` 视角拆时价和竞业（家庭时间也是成本）
- 想重启职场 → 转 `perspective-employee` 视角拆可迁移资产
