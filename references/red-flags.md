# 死亡信号红线 Checklist（一眼看出哪快死了）

## 先认清楚（最重要）

各层的致命信号散落在五个 layer 文件里。这张表把它们**汇总成一张红线清单**——拆完五层，让学员自查，命中几条红线 = 距死多远。红线不是"薄弱"，是"已经在流血"。

> 用法：拆完五层后，把这张表甩给学员，让他自己打勾。命中 ≥3 条红线，基本可以判"不能跑 / 先大改"。

## 道层红线
- ☐ 没有任何人**真付过钱**（只有"感兴趣""想了解"）
- ☐ 用"平台 / 生态 / 赋能 / 闭环 / 抓手"描述自己在做什么
- ☐ 客户画像 = "所有中小企业""所有爱美的人"（等于没客户）
- ☐ 伪道信号：把风口 / 证明自己 / 跟风 / 面子 / 焦虑当道；用"帮助更多人"包装赚钱

## 法层红线
- ☐ 只有一次性收入，没想过复购
- ☐ 没算过回本线（一天卖多少、多久回本不知道）
- ☐ 单笔毛利算不清，靠"大概赚"在撑
- ☐ 一单一结，没有年框 / 没有持续合同

## 术层红线
- ☐ 只有"准备"，没有任何下一步动作
- ☐ 获客全靠熟人介绍，没有可复制打法
- ☐ 客户从知道你到掏钱，没有清晰步骤
- ☐ 连续 3 个月零新客

## 器层红线
- ☐ 流程全在老板一个人脑子里
- ☐ 客户在微信聊天记录里，没沉淀到可触达地方
- ☐ 老板病三天，生意就瘫
- ☐ 没有可复用资产（模板 / 素材 / 系统 / 内容）

## 势层红线
- ☐ 说不清"凭什么是你"，把"很火"当理由
- ☐ 把风口当势（"AI 火所以我做"）
- ☐ 窗口什么时候关，完全没概念
- ☐ 大厂明天进场，你活不过半年

## 组合判死刑（命中即危险）

- **道红线 + 法红线** → 这不是生意，是想法。立刻停。
- **器红线 + 术红线** → 人在系统在，人走系统瘫。扩不动。
- **势红线 + 道伪** → 追着风口给伪道加速。死得最体面也最惨。

## 话术

> 你别说"我哪都不行"——你命中的是这 3 条红线，每一条都在流血。先堵最上面那道（道/法），下面那几道会自己缓。全堵一遍等于不堵，先堵一道。
