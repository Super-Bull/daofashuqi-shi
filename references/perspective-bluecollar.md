# 视角：蓝领手艺（家政/月嫂/维修/装修/理发/厨师）

> 适用：靠手艺吃饭的人——家政、月嫂、育婴师、维修工、装修师傅、理发师、厨师，以及想从"干活"升级到"带队伍"的小包工头。这拨人离钱最近，但离"资产"最远。

## 一、五层长相（蓝领手艺眼里的道法术器）

| 层 | 这拨人的真实长相 | 典型误区 |
|---|---|---|
| 道 | 你卖力气还是卖手艺——同样的活，单价能差十倍 | 把自己当"干活的"，不当"手艺人"，定价永远上不去 |
| 法 | 接单收入的天花板：一天就 24 小时，不招人不带徒就到顶 | 用时间换钱换到 45 岁，身体先退休 |
| 术 | 客户从哪来：平台派单 vs 私域口碑——平台抽成后你剩多少 | 全靠平台派单，客户认平台不认你 |
| 器 | 工具、标准化流程、学徒体系 vs 全靠一双手 | 手艺在手上，带不走也传不下去 |
| 势 | 蓝领收入上升、服务规范化、AI 替代难（稳当）、社区化 | 以为"体力活没前途"，实际是唯一没被 AI 冲的池子 |

## 二、典型死法映射

- **道层死法 · 卖力气** → 什么便宜干什么，干了十年还是日薪，没攒出任何溢价
- **法层死法 · 单干天花板** → 不招人不带徒，收入锁死在自己的工时里
- **术层死法 · 平台锁定** → 派单依赖，抽成越来越高，客户资料不在自己手里
- **器层死法 · 无保障** → 没合同没社保没工伤险，出一次事回到解放前
- **势层死法 · 体力衰退** → 45 岁后接不动重活，又没有转型的积累

## 三、势从哪来

1. **蓝领收入上行**：用工荒+服务升级，好手艺的时薪在涨——溢价属于"有口碑的人"。
2. **规范化**：家政、维修行业在走向持证和标准化——早规范早吃红利。
3. **AI 替代难**：上门服务、动手活儿是 AI 最难碰的领域——这是被低估的避风港。
4. **社区私域势**：小区口碑、微信群、老客户转介绍——离你最近的现金流。

## 四、归因分类

| 类型 | 真相 |
|---|---|
| 手艺人 | 有真本事——卡在不会给自己定价 |
| 平台型 | 稳定但被抽成——客户不是你的 |
| 小包工头型 | 开始带人——卡在不会分钱和管人 |
| 转型型 | 想开工作室/公司——先攒客户再租门面 |

## 五、专属漏洞（诊断重点看）

1. **私域客户怎么攒**：每单做完加微信、进群、留卡片——客户认识你，你才不怕平台抽成和规则变化。
2. **报价从日薪到项目制**：按天卖是最亏的，按"干完这个活收多少钱"卖，同样的活能贵三成。
3. **带徒弟=从日薪到包工的第一步**：你干活的时间有上限，带人干活没有。
4. **保障是基础设施**：工伤险、服务合同、收款凭证——别等出事才想起来。
5. **手艺标准化**：把你干了十年摸出的门道写成流程，才传得下去、卖得出去。

## 六、金句池（沙龙直接用）

- "平台派单是方便，也是抽成和锁死。"
- "手艺人最后的底气，是客户认识你，不是平台认识你。"
- "按天卖力气是最亏的卖法，按活收钱。"
- "带一个徒弟，才是你从日薪到包工的第一步。"
- "AI 抢的是坐办公室的，抢不了上门干活的——这是你的避风港。"

## 七、数据纪律

- **能用（定性）**：服务业用工需求旺、蓝领时薪上行、平台抽成普遍（普遍共识）。
- **禁用**：编"月嫂平均月薪 X""家政市场规模 X 亿"——地域和档次差太远，编了就是误导定价。

## 八、转诊线

- 劳务纠纷、工伤赔付、合同 → 找法律援助和劳动部门，别用 AI 的话维权
- 开公司/带团队（≥30 万投入）→ 转 business-inference-core
- 副业/手艺教学变现 → 可转 `perspective-sidehustle` 视角拆
- 长期伤病、体力衰退焦虑 → 走 `emotional-companion.md` 危机边界，暖着转介——体力劳动者的身体焦虑最容易被"扛一扛"三个字耽误
