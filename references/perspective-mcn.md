# 视角：MCN / 达人经纪（网红经纪）

> 适用：MCN 机构老板、达人经纪、直播公会运营。这行的本质是**赌徒生意**：签十个成一个，成的那个养全部。多数机构死在"不会算账"和"把达人当资产不当人"。

## 一、五层长相

| 层 | 这拨人的真实长相 | 典型误区 |
|---|---|---|
| 道 | 你卖的是"达人时间"还是"品牌效果" | 签人只看粉丝量，不看变现路径——粉丝是假的，账才是真的 |
| 法 | 单达人产出 − 签约成本 − 运营成本 − 分成 = 真实利润 | 流水当利润，GMV 当收入，账上看着热闹兜里空空 |
| 术 | 达人从哪来（星探/推荐/自孵化）、商单从哪来 | 全靠商务喝酒拿单，机构没有可复制的获客系统 |
| 器 | 内容中台、选品系统、数据看板、法务合同模板 | 全靠运营个人能力，人一走全带走 |
| 势 | 平台规则、达人话语权、AI 数字人冲击 | 平台一改分成规则，一夜回到解放前 |

## 二、典型死法映射

- **道层死法 · 粉丝幻觉** → 花重金签百万粉达人，结果商单转化零——粉丝量不等于变现力
- **法层死法 · 流水幻觉** → GMV 一个亿，退货 40%，投流 30%，分完所剩无几——拿流水骗自己
- **术层死法 · 喝酒商务** → 商单全在老板的酒桌上，没有销售系统，老板病倒公司停摆
- **器层死法 · 人被绑死** → 达人跟运营个人走，运营离职达人跟着走，机构只剩logo
- **势层死法 · 平台宿主** → 平台规则一变（限流/改分成/封类目），业务直接腰斩——你的势是租来的

## 三、势从哪来

1. **达人话语权在涨**：头部达人开始自建团队、跳过机构——中间商的空间在被压缩，只有"真提供服务"的机构活得下去。
2. **AI 数字人冲击中腰部**：直播、短视频的中低端产能正在被 AI 拉平——纯执行型的达人溢价在跌，"有人格信任"的在涨。
3. **品牌预算收紧但向效果集中**：品牌不为曝光付钱了，为成交付钱——会做效果的机构吃香，只会刷量的出局。
4. **合规成本涨**：税务、广告法、直播带货规范的整治在筛人——灰产玩法（刷单、虚假宣传）的窗口在关。

## 四、归因分类

| 类型 | 真相 |
|---|---|
| 星探型 | 靠签人起家，最容易犯"重签轻养"——签是赌博，养才是生意 |
| 运营型 | 靠孵化起家，最容易犯"赌一个"——All in 一个达人，达人塌方机构陪葬 |
| 商务型 | 靠接单起家，最容易犯"没有产品"——本质是黄牛，利润越压越薄 |
| 供应链型 | 靠货起家，最容易犯"不重视人"——货能复制，人复制不了 |

## 五、专属漏洞（诊断重点看）

1. **单达人经济模型**：签一个达人，从签约到回本几个月？月均净贡献多少？——算不出这个数的机构，签人是撒钱。
2. **塌方保险**：头部达人翻车/出走，公司能不能活过 6 个月？——把身家押在一个网红身上的，都是赌徒。
3. **达人归属权**：账号、粉丝、商务关系在谁手里？——合同签清楚了吗？没签清楚，你是在替别人养号。
4. **商单集中度**：前三大客户占收入多少？超 50% 的，一个客户流失就要裁员。
5. **退货和投流账**：GMV − 退货 − 投流 − 分成 − 运营，最后剩多少？——把真实净利率算出来，多数机构会惊出一身冷汗。

## 六、金句池

- "GMV 是流水的，利润才是自己的。"
- "签达人签的是一个你会不会养的人，合同只是附件。"
- "把身家押在一个网红身上的，不叫机构，叫赌桌。"
- "达人跟运营走的公司，你签的那张约是借条。"
- "平台给你的势是租来的，随时涨租——自己的获客系统才是买的。"

## 七、数据纪律

- **能用（定性）**：MCN 行业亏损面大、达人自建团队趋势、AI 冲击中低端产能、合规整治趋严（均为普遍共识）。
- **禁用**：编"X% 的 MCN 在亏损""达人签约均价 X 万"——自媒体唱衰文的流量话术，别引用。

## 八、转诊线

- 股权融资/多轮投资架构（≥30 万外部资金进场）→ 转 business-inference-core
- 达人合同纠纷、税务合规 → 找律师和财务，别自己拟
- 想转型做品牌/供应链 → 转 `perspective-crossborder`（若做跨境）或商业深推演
- 连亏 6 个月以上、想散伙 → 先算清"散伙成本"再谈感情
