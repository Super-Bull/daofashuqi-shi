# 视角：教培校长（培训机构 / 校长 / 老板）

> 适用：开培训班、托管、素养教育、职业技能机构的校长和老板。这拨人卡在"政策+招生成本+师资流失+预收费监管"四座山之间，最容易把"学生多"当"生意稳"。

## 一、五层长相

| 层 | 真实长相 | 典型误区 |
|---|---|---|
| 道 | 替家长/学员解决什么"确定性结果"（提分/上岸/就业）？ | 把"我有证有场地"当道 |
| 法 | 盈利模型：获客成本、满班率、续费、师资成本占比 | 只看报名数不看满班率和续费 |
| 术 | 招生（地推/转介绍/抖音）、成交、交付 | 招生全靠烧钱投流，转介绍没机制 |
| 器 | 师资、课程体系、教务系统、场地 | 器=几个好老师，老师一走生源走 |
| 势 | 政策风向、出生率、就业市场、AI 替代 | 误把"刚需"当"永远刚需" |

## 二、典型死法

- **道层死法 · 结果模糊** → 承诺"提升"但不承诺可量化结果，家长不续
- **法层死法 · 获客贵** → 招生成本吃掉毛利，满班率上不来必亏
- **术层死法 · 转介绍裸奔** → 老客推荐无机制，永远在买新客
- **器层死法 · 名师依赖** → 好老师即公司，老师单飞带走上百学员
- **势层死法 · 政策盲** → 政策一变赛道消失（如学科类），没预案

## 三、势从哪来

1. **政策势**：监管收紧（预收费监管、办学许可）抬高合规成本。
2. **人口势**：出生率下行，K12 需求长期收缩，成人/银发/职业是转移方向。
3. **AI 替代势**：标准化知识传授被 AI 抹平，机构价值要转向"陪伴+结果交付"。
4. **就业势**：职业技能培训随就业市场冷热剧烈波动。

## 四、归因分类

| 类型 | 真相 |
|---|---|
| 名师型 | 靠一两个老师撑门面，抗风险为零 |
| 营销型 | 会招生不会交付，口碑崩 |
| 情怀型 | 为理想办学，不认账 |
| 加盟型 | 买牌子不会本地化 |

## 五、专属漏洞

1. 满班率/续费率算不清，报名数掩盖亏损
2. 预收费监管裸奔，资金池一查就死
3. 师资无备份，单点依赖
4. 政策预案为零，赛道说没就没

## 六、金句池

- "报名多不等于赚钱，满班率和续费才是你的命。"
- "好老师一走，带走的是你半壁生源，不是一个人。"
- "你把'提升'当承诺，家长要的是'上岸'，两字差的就是续费。"
- "政策一纸文件，你十年的赛道说没就没，你居然没预案？"

## 七、数据纪律

- **能用（定性）**：出生率下行致 K12 需求收缩（国家统计局口径，可引）；预收费监管为现行政策（引官方文件）。
- **禁用**：编"续费率 X%""行业规模 X 亿"无来源数字，标「假设」。

## 八、转诊线

- 已投 ≥30 万、想做连锁/融资/跨城市 → 转 business-inference-core
- 纯问"怎么写招生文案" → 指给内容工具
