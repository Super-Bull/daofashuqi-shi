# 视角：退役运动员（转型再就业）

> 适用：退役/即将退役的专业运动员、体校生、半职业选手。你们把最好的年纪给了赛场，社会却欠你们一张"使用说明书"——转型不是从零开始，是把运动员资产翻译成市场语言。

## 一、五层长相

| 层 | 这拨人的真实长相 | 典型误区 |
|---|---|---|
| 道 | 你要的是"稳定饭碗"还是"把一身本事接着卖" | 只认体制内安置一条路，不知道自己还会啥 |
| 法 | 你的稀缺性在哪：金牌光环？专项技能？极端自律？ | 光环当本事用——成绩是过去的，市场只买现在的价值 |
| 术 | 谁需要"一个拿过名次的人"：青少年培训、企业军训、赛事运营、品牌代言 | 只投简历不主动卖，简历上除了成绩没别的话说 |
| 器 | 可迁移资产：训练方法论、伤病管理、团队带领、镜头表现力 | 不翻译不沉淀，一身本事烂在肚子里 |
| 势 | 体育培训、赛事经济、运动员 IP 在涨；纯体力市场在跌 | 只会"能干体力活"，忘了"会教人"才值钱 |

## 二、典型死法映射

- **道层死法 · 身份戒断** → 退役后三年还在"想当年"，接受不了从冠军变素人，啥都不投
- **法层死法 · 光环折现失败** → 以为金牌能当饭吃，市场问"你能给我带来啥"时哑火
- **术层死法 · 只投简历** → 简历上只有比赛成绩，HR 看不懂"退役运动员"值多少钱
- **器层死法 · 资产归零** → 不把训练方法、带队经验、镜头感翻译成市场语言，等于从零开始
- **势层死法 · 吃青春饭到老** → 三十岁还靠"能跑能跳"接活，四十岁市场不再要"体力"时要啥没啥

## 三、势从哪来

1. **体育培训热**：家长愿意为"专业的人教孩子"付钱——你的专项成绩在这里直接变现，比去公司写 PPT 值钱。
2. **企业军训/团建/赛事运营**：需要"能镇场、懂行、扛得住"的人，运动员是稀缺供给。
3. **运动员 IP**：短视频、赛事解说、体育经纪——镜头表现力和职业故事是现成的内容资产。
4. **AI 替代不到的地方**：AI 能讲训练理论，替不了"一个真拿过名次的人站在场边"——线下交付是你的护城河。

## 四、归因分类

| 类型 | 真相 |
|---|---|
| 成绩型 | 光环最亮，也最容易摔惨——市场只为"现在能干啥"付钱，不为"过去赢过"付钱 |
| 默默型 | 没名次但有一身真本事，最缺的是"敢开口卖"——你缺的不是能力是定价的胆子 |
| 伤病型 | 一身伤病提前退，别硬扛重活，"教"比"练"适合你 |
| 半职业型 | 进过队没留队，最容易高不成低不就——先解决"靠啥吃饭"再谈理想 |

## 五、专属漏洞（诊断重点看）

1. **翻译测试**：把你的经历翻译成一句客户听得懂的话——"我练了十年游泳，能带 6-12 岁孩子从怕水到游完 25 米"。翻不出来的，先补这课。
2. **身份戒断期**：退役头一年最危险——不急着"找个班上"，先给自己 90 天把资产盘一遍（会啥、认识谁、能教啥）。
3. **伤病定价**：一身伤病还想靠体力吃饭是死路；把伤病经验翻译成"防护/康复/教学"才是出路。
4. **圈子单一是双刃剑**：体育圈熟人遍地，但圈外零连接——前三个月逼自己每周认识 2 个圈外人。
5. **学历/证书补位**：教练证、教师资格证、急救证——不是万能，是让圈外人信你的最低成本敲门砖。

## 六、金句池

- "金牌是过去的，市场只给现在的你付钱。"
- "退役不是从零开始，是换语言重新介绍自己。"
- "一身伤病不是负资产，是你教人别受伤的本钱。"
- "圈子熟是假象——圈外没人认识你，你就没有市场。"
- "先解决靠啥吃饭，再谈热爱和理想，顺序反了全乱。"

## 七、数据纪律

- **能用（定性）**：体育培训市场需求增长、退役安置渠道有限、运动员 IP 有变现空间（均为普遍共识）。
- **禁用**：编"退役运动员 X% 再就业困难""培训教练平均月入 X 万"——招生机构的焦虑话术，别引用。

## 八、转诊线

- 退役安置政策、编制考试 → 问当地人社/体育局，别问 AI
- 伤病治疗/伤残鉴定 → 走医疗和鉴定机构
- 要开俱乐部/培训公司（≥30 万投入）→ 转 business-inference-core 深算
- 退役后情绪低落、自我否定严重 → 先接住再拆，别急着推动作；持续低迷转介心理专业支持
