# 视角：跨境电商（B2C · 亚马逊/独立站/Temu）

> 适用：做亚马逊、独立站、Temu/TikTok Shop 的卖家。区别于外贸 B2B（跟公司客户喝大酒谈账期），跨境电商是**跟平台和算法谈恋爱"——规则你说了不算，封号、压价、封店，一夜回到解放前是常态。

## 一、五层长相

| 层 | 这拨人的真实长相 | 典型误区 |
|---|---|---|
| 道 | 你卖的是"中国供应链差价"还是"自己的牌子" | 只会铺货赚差价——没有牌子，价格战打到底 |
| 法 | 售价 − 货 − 物流 − 平台佣金 − 广告 − 退货 = 单件净利 | 只看售价不看全账，退货率和广告费能吃掉全部利润 |
| 术 | 流量从哪来：平台自然流、广告投放、站外内容 | 全部押平台广告，停投就断流，等于给平台打工 |
| 器 |  Listing、review 数、店铺权重、供应链 | 店铺就是全部资产，一封店全部归零 |
| 势 | 平台政策周期、关税、汇率、AI 内容拉平门槛 | 把平台红利当自己本事，红利退潮裸泳 |

## 二、典型死法映射

- **道层死法 · 铺货思维** → 上架一千个 SKU 碰运气，没有一款打透——库存是坟场
- **法层死法 · 全账不清** → 售价 20 美元看着美，退货 15%+广告 8 美元+物流 5 美元，卖一单亏一单还不知道
- **术层死法 · 广告鸦片** → 停投流就零单，永远在给平台交租；没有自然流和复购，规模越大越亏
- **器层死法 · 店铺即命** → 封店、跟卖、投诉，一次事故全部清零；没有独立站、没有客户名单，等于裸奔
- **势层死法 · 红利错配** → 把 Temu 补贴期/平台新店流量当"我会做电商"，政策一变原地倒闭

## 三、行业困局（这行到底卡在哪）

平台从红利期进收割期、广告依赖（一停投放就没单）、封店风险（一次违规全店归零）、独立站资产没建。单件账算不清（货 + 运费 + 平台扣点 + 退货）就会「越大越亏」。平台是租来的地，你在上面盖的楼随时可能被推倒。

## 四、大众困局（这拨人常见的误会）

- "铺货就能出单"——错。铺货是赌平台给流量，不是本事。
- "广告投得越多卖得越多"——错。广告一停就归零，那是买来的订单。
- "先做大 GMV 再谈利润"——错。算不清单件账，越大越亏。

## 五、势从哪来

1. **平台红利期 → 收割期**：每个新平台（ Temu/TikTok Shop ）都有补贴窗口——窗口期是给你建护城河（评价、复购、供应链）的，不是给你躺赚的。
2. **合规成本涨**：税务（VAT/销售税）、产品认证、知识产权整治在收紧——铺货杂牌的空间在关，合规品牌的空间在开。
3. **AI 把"内容生产"拉平**：Listing、图片、视频素材的生产门槛被打穿——拼的不再是"会不会做素材"，是"有没有产品和供应链"。
4. **独立站+DTC 回暖**：平台税越抽越重，"把客户变自己的"（邮件列表、私域、复购）从可选项变必选项。

## 六、归因分类

| 类型 | 真相 |
|---|---|
| 铺货型 | 门槛最低死得最快——库存和价格战双重绞杀 |
| 精品型 | 最可能活，但容易犯"单一 SKU 依赖"——一款爆品吃三年，竞品一来全塌 |
| 品牌型 | 天花板最高，也最烧钱——先算清"品牌溢价够不够覆盖建站和内容成本"再 All in |
| 跟风型 | 看别人做 Temu 赚钱就进场——平台末班车接盘侠，红利全被前几波吃了 |

## 七、专属漏洞（诊断重点看）

1. **单件全账**：拿一款主力产品，把"货+物流+佣金+广告+退货+资金占用"全算进去，真实净利率多少？——低于 15% 的，规模越大死得越快。
2. **封店生存测试**：主力店铺明天被封，你还有什么？（独立站？客户名单？备用店铺？供应链？）——啥都没有的，你是在给平台免费养用户。
3. **SKU 集中度**：前 3 款产品占收入多少？超 70% 的，竞品一个降价你就归零。
4. **复购和客户资产**：买过你东西的人，你还能第二次触达吗？——亚马逊客户是平台的，独立站客户才是你的。
5. **库存周转**：一批货压几个月卖不掉，资金占用+仓储费 quietly 吃掉利润——库存是跨境电商最大的隐形杀手。

## 八、金句池

- "GMV 是平台的，利润才是自己的；用户是平台的，名单才是自己的。"
- "广告是租来的流量，独立站是买来的资产。"
- "平台红利是给你建护城河的窗口，不是让你躺赚的温床。"
- "卖一单亏一单不可怕，可怕的是你忙着爆单，忘了算账。"
- "封店那天你还有什么，决定了你是在做生意还是在租柜台。"

## 九、数据纪律

- **能用（定性）**：平台规则多变、合规成本上升、铺货模式式微、独立站/DTC 趋势（均为普遍共识）。
- **禁用**：编"跨境电商平均净利率 X%""亚马逊封号潮涉及 X 万卖家"——卖课机构的焦虑话术，别引用。

## 十、转诊线

- 大额投入/多平台扩张/融资（≥30 万）→ 转 business-inference-core 深算
- 税务合规（VAT/销售税）、知识产权纠纷 → 找跨境律师和税务师
- 封店/资金冻结 → 走平台申诉和专业服务商，这是应急不是诊断
- 做 B 端转型（接海外公司订单）→ 转 `perspective-foreign-trade`
