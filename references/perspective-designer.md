# 视角：设计师（UI / 平面 / 工业 / 室内）

> 适用：靠审美和软件吃饭的设计师，全职或接单。典型状态——"AI 设计工具一来，怕被替又不敢不用"。对应你社群里那批"手艺好、但只会工时换钱、不会把设计变成生意"的设计人。

## 一、五层长相（这拨人眼里的道法术器）

| 层 | 真实长相 | 典型误区 |
|---|---|---|
| 道 | 做美/解决问题，但没想清"客户为设计付多少、为什么" | 把审美当生意，不看商业结果 |
| 法 | 接单/全职，没设计产品化（模板/课程/咨询） | 工时换钱，越忙越穷 |
| 术 | 靠平台接单/熟人，不会做个人 IP | 比稿，免费出力 |
| 器 | Figma/PS + AI 设计工具，效率翻倍 | 怕被超，死守老工具 |
| 势 | AI 普及，低端设计被替，高端咨询势起 | 焦虑被替，不升维 |

## 二、典型死法映射

- **道层 · 审美思维** → 好看但客户不买单。
- **法层 · 工时换钱** → 不产品化，收入有天花板。
- **术层 · 比稿** → 免费干活，转化低。
- **器层 · 拒 AI** → 效率落后，报价无优势。
- **势层 · 不升维** → 停在出图，被工具替掉。

## 三、行业困局（这行到底卡在哪）

低价竞争、客户压价、AI 替掉低端出图。AI 对设计师的价值不是"让你失业"，是**把重复出图交给它，你往上做策略**——从"画图工"变成"帮客户解决问题的人"。

## 四、大众困局（这拨人常见的误会）

- "AI 设计免费了，我完了"——错。替低端出图，不替策略判断。
- "设计师要转码"——错。要转的是咨询和审美决策。
- "接单越多越好"——错。工时换钱，没沉淀。

## 五、势从哪来

1. **咨询势**：从做图到做策略，客单价翻倍。
2. **效率势**：AI 出图，你审，交付快报价低。
3. **产品势**：模板/课程/组件库，一次做反复卖。

## 六、归因分类

| 类型 | 真相 |
|---|---|
| 工时型 | 接单为生，无产品 |
| 焦虑型 | 怕 AI，不用 |
| 升维型 | 想做咨询但不会 |

## 七、专属漏洞

1. **道 · 审美思维**：不看结果。
2. **法 · 无产品**：工时换钱。
3. **术 · 比稿**：免费出力。
4. **器 · 拒 AI**：效率落后。
5. **势 · 不升维**：被工具替。

## 八、金句池

- "AI 替你出图，但替不了你判断这张图对不对。"
- "设计师的尽头不是画图，是帮客户解决问题。"
- "比稿比来的单，都是最便宜的。"
- "工时换钱的天花板，就是你一天 24 小时。"

## 九、数据纪律

- 本人群无特定权威数据，用户没说就标「假设」。AI 替代率只说"低端出图被冲"，不编百分比。

## 十、转诊线

- 想做设计产品化/个人 IP → 转创作者运营。
- 纯问"哪个 AI 工具好" → 不归本 skill，指给工具测评。
