# 视角：职场人（泛打工族 · 跳槽/转岗/35岁/被裁/该不该离职）

> 适用：普通公司上班的人，纠结走留、转型、跳槽、35 岁危机、被裁后怎么办的人。区别于 `perspective-bigtech`（大厂人有光环/期权/螺丝钉化三专属坑）和 `perspective-internal-ai`（被派去推 AI 的中层）。这是最普世的一群人——五层框架对打工人同样成立，只是每层问法不同。

## 一、五层长相（打工人眼里的道法术器）

| 层 | 这拨人的真实长相 | 典型误区 |
|---|---|---|
| 道 | 你上班到底图什么：钱、成长、稳定、意义——四样最多占两样，你得知道自己选的是哪两样 | 从没选过，只是"大家都上班"，所以一难受就想逃 |
| 法 | 你的收入结构：卖时间还是卖结果？工资是天花板还是跳板？ | 把工资当唯一的收入来源，人生绑死在一个老板的预算上 |
| 术 | 好机会是投简历投来的，还是被找到的？你的外部可见度 | 只在离职那一刻才看招聘软件，平时市场不知道你存在 |
| 器 | 可迁移资产：技能、作品、人脉，还是只有工龄 | 把工龄当资本——工龄是贬值的，不是增值的 |
| 势 | 你的行业/岗位在升值还是贬值？你的经验每年在涨还是在折旧 | 以为经验自动升值，其实多数经验每年在打八折 |

## 二、典型死法映射

- **道层死法 · 逃避型跳槽** → 用跳槽解决所有问题：同事处不来、活太累、领导傻——跳了三次，问题跟着三次
- **法层死法 · 单源收入** → 工资是唯一现金流，一失业全家停摆，被迫接受任何垃圾 offer
- **术层死法 · 隐形人** → 活干得最多，存在感最低，升职加薪永远轮不到，市场也不知道你
- **器层死法 · 工龄幻觉** → 十年经验=一个经验用十年，新人半年就能接手你的活
- **势层死法 · 逆势坚守** → 行业在塌（教培/地产/传统媒体），还在里面比谁熬得久

## 三、行业困局（这行到底卡在哪）

AI 先拉平标准化中间环节（翻译、初级文案、初级设计、初级分析）；35+ 性价比危机（产出没比年轻人贵出那么多）；岗位持续贬值（经验每年在打折）；收入单源（工资是唯一现金流，一失业全家停摆）。

## 四、大众困局（这拨人常见的误会）

- "公司稳定我就稳"——错。公司稳，不等于你不可替代。
- "熬资历总会涨薪"——错。工龄在贬值，不是增值。
- "跳槽能解决一切"——错。上家的问题，下家还会再遇到。

## 五、势从哪来

1. **岗位贬值**：AI 先拉平的是"可标准化的中间环节"——翻译、基础文案、初级设计、初级分析。你的经验如果停在三年前，每年在贬值。
2. **年龄曲线**：多数岗位有隐形的性价比天花板，超线后不是不给你活路，是不给你溢价。
3. **行业迁移**：城市和产业在洗牌，守着正在下沉的行业，努力是负收益。
4. **副业与个体势**：越来越多人靠"技能+外部可见度"活着，不再依赖一个老板——这是打工人最大的新势。

## 六、归因分类

| 类型 | 真相 |
|---|---|
| 稳定型 | 求稳没错，但稳不能只有工资一条腿，得配可迁移资产 |
| 成长型 | 方向对，但只在公司内部成长=成长半径被公司锁死 |
| 过渡型 | 明知是过渡，结果过渡了五年——过渡要有截止日 |
| 逃避型 | 不是想走，是不想面对。跳槽是解药也是麻醉剂，看剂量 |

## 七、专属漏洞（诊断重点看）

1. **跳槽三问**：为什么是现在（上一家的问题在新家会不会重演）？为什么是这家（对方图你什么）？你要的这家给得了吗？三问答不上来，别跳。
2. **"被裁"后的空窗期用法**：空窗期不是休假，是把你从"公司零件"还原成"市场的人"的窗口期——作品、人脉、外部可见度，这三样哪个都行，就是别纯躺着。
3. **副业时机**：主业还在上升期就别分心；主业见顶或行业下沉，副业不是可选项是必答题。
4. **要不要转行**：转行不是从零开始，是把可迁移的层（技能/人脉/方法论）打包带过去。啥都带不过去的转行，是逃难。
5. **35 岁的真问题**：35 岁危机不是年龄危机，是"性价比"危机——你的产出没比年轻人贵出那么多，你就危险。

## 八、金句池（沙龙直接用）

- "找工作，是在给自己的能力和市场定价。"
- "跳槽逃避的问题，下家还会再遇到一次。"
- "公司买的是你的现在，市场买的是你的将来。"
- "十年工作经验？很可能是一个经验用了十年。"
- "工资是你唯一的收入，就是你把命门交给了别人。"

## 九、数据纪律

- **能用（定性）**：35 岁职场现象普遍、AI 对标准化岗位的替代加速、副业人群扩大（均为普遍共识）。
- **禁用**：编"某行业平均薪资 X""跳槽涨薪 X%"——地域、行业、岗位差太远，编了就是误导。

## 十、转诊线

- 涉及劳动仲裁、竞业协议、工伤/职业病的权益 → 找律师和劳动部门，本 skill 不接
- 情绪持续低落、失眠绝望 → 走 `emotional-companion.md` 危机边界，暖着转介，不硬拆
- 想创业/单干（0→1 阶段）→ 可转 `opc-playbook` 或 `perspective-founder` 视角继续拆
- 已投重资创业（≥30 万/带团队）→ 转 business-inference-core
