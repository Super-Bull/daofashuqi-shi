# 视角：传统实体门店老板（餐饮 / 零售 / 本地服务）

> 适用：自己开店、有房租有员工、靠每天流水活着的老板。与 OPC 正好镜像——OPC 是零成本独狼，他是重成本扛压。沙龙现场坐得最多的往往就是这拨人。

## 一、五层长相（这拨人眼里的道法术器）

| 层 | 这拨人的真实长相 | 典型误区 |
|---|---|---|
| 道 | 我为谁解决什么不可替代的问题？很多老板答"我做餐饮的"——这是行业，不是道 | 把"开店"当道，没想清替谁解决什么痛点 |
| 法 | 盈利模型：人效、翻台、客单价、复购率。这是生死线 | 只算"一天卖多少"，不算"人效够不够 cover 房租人工" |
| 术 | 获客（美团/抖音/私域）+ 交付（出餐/服务稳定） | 等客上门，或只靠平台投流 |
| 器 | 收银系统、会员系统、短视频工具、AI 写文案 | 器=装修+设备，而非能沉淀客户的系统 |
| 势 | 线下流量在往哪走：商圈转移、平台抽佣、消费降级 | 还在赌"位置好就稳"，不知客流已被平台截胡 |

## 二、典型死法映射（五层定位）

- **道层死法 · 没想清替谁解决什么** → 跟风开店，品类扎堆，开业即同质化
- **法层死法 · 人效算不清** → 看着流水不错，一算人效覆盖不了房租人工，月月亏
- **术层死法 · 会员不沉淀** → 每天都是新客，没有复购，等于每天重新创业
- **器层死法 · 平台依赖** → 客流 100% 来自美团/抖音，平台一抽佣/一降流就死
- **势层死法 · 逆势硬扛** → 消费降级期还涨客单价、还扩店，撞上闭店潮

## 三、势从哪来

1. **消费降级势**：2025 全国餐饮人均消费 33 元，较两年前降 23.6%（红餐产业研究院）。客人钱包薄了。
2. **平台抽佣势**：外卖平台商家综合成本占比 20-25%、60% 餐饮门店亏损（市场监管总局调研）。你是给平台打工。
3. **商圈转移势**：人流从街边店往商场、从商场往社区转移，老位置不等于老客流。
4. **成本刚性势**：房租占营收 15-25%、人力 25-30%（中国饭店协会）——这两条降不下来。

## 四、归因分类（这拨人怎么走到今天的）

| 类型 | 真相 |
|---|---|
| 跟风型 | 看别人赚钱就开，没做过功课，撞上闭店潮 |
| 手艺型 | 东西好吃/好用，但不会算账、不会获客，死在法术 |
| 闲钱型 | 有本金没精力，雇人管店，人效失控 |
| 被租约坑型 | 势层出问题，租约和商圈变化没预判 |

## 五、专属漏洞（诊断时重点看）

1. **道 ≠ 行业**：问"你替谁解决什么痛点"，答"我做餐饮的"= 道层空洞
2. **不会算人效**：没有"坪效/人效 vs 房租人工"的账，凭感觉经营
3. **会员零沉淀**：没有私域、没有复购机制，全靠新客
4. **平台单一依赖**：客流来源 ≥70% 来自一个平台 = 高危
5. **逆势扩张**：闭店潮里还加店、还涨价，必死

## 六、金句池（沙龙可直接用）

- "你不是开了个店，你是租了个位置，每天等客人施舍。"
- "客流不是你的，是美团/抖音的。它哪天不给你推了，你第二天就揭不开锅。"
- "会员不沉淀，等于每天重新创业——昨天的 100 个客人，今天一个都不认识你。"
- "一碗面 33 块（2025 人均），你还想着靠涨价 cover 房租？客人比你先跑。"
- "装修再漂亮，生意思不了客，就是给房东交的展览费。"

## 七、数据纪律

- **能用**：全国餐饮平均闭店率 22.66%、一线城市 35%（NCBD/极海，2024-2025）；2024 年倒闭餐饮公司近 300 万家（企查查）；2025 餐饮人均消费 33 元降 23.6%（红餐）；外卖商家综合成本 20-25%、60% 亏损（市场监管总局调研）；个体户 2024 退出 1695.7 万户（市场监管总局）。
- **谨慎**：某报道"实体店闭店率 37%"口径不明，沙龙慎用，要引就引 NCBD 的 22.66%。
- **禁用**：把"闭店率"（关了多少店）和"注销个体户"（退了多少人）混为一谈——量级差百倍。

## 八、转诊线

- 已投入 ≥50 万、有 ≥3 名员工、月月算不清账 → 超出 3 分钟轻量自检，建议转深度陪跑（你的 B 端服务）或 business-inference-core
- 连锁 ≥3 店、想做品牌化 → 转 moudao 做扩张规划
- 纯问"怎么写大众点评文案""怎么拍抖音" → 不归本 skill，指给内容工具
