# 视角：品牌主理人（自有品牌 / 设计师品牌 / 新消费）

> 适用：自己创牌、当主理人，操心产品+调性+带货整盘的人。区别于 `perspective-franchisee`（加盟代理别人的牌）。这拨人最容易把"我喜欢"当"市场要"，把"调性"当"道"。

## 一、五层长相

| 层 | 真实长相 | 典型误区 |
|---|---|---|
| 道 | 品牌替哪群人解决什么身份/情绪/功能需求？ | 把"审美在线"当道，没想清替谁解决什么 |
| 法 | 盈利模型：毛利、动销、库存周转、复购 | 只看GMV不看净利，库存压死现金流 |
| 术 | 内容种草、达人投放、私域、线下快闪 | 全靠投流买量，停投就归零 |
| 器 | 供应链、代工、设计、CRM、履约 | 器=一个代工厂，被上游卡脖子 |
| 势 | 情绪红利窗口、平台风向、品类周期 | 误把"赛道火"当"我的势" |

## 二、典型死法

- **道层死法 · 调性即道** → 沉迷视觉和故事，没想清客户为啥非买你不可
- **法层死法 · 库存癌** → 押错款、压一堆货，毛利全变仓储费和跌价
- **术层死法 · 投流依赖** → 流量靠烧钱买，ROI 一掉就崩
- **器层死法 · 代工绑架** → 核心工艺在代工厂手里，一换厂就断供或泄版
- **势层死法 · 追风口** → 哪个品类火跟哪个，永远在追别人尾巴

## 三、势从哪来

1. **情绪红利势**：某类身份认同（如"新中式""松弛感"）窗口期短，慢半拍就过剩。
2. **平台风向势**：小红书/抖音内容权重变化，决定种草成本。
3. **供应链势**：小批量快反能力是护城河，大厂柔性供应链下沉会抹平你的"独特"。

## 四、归因分类

| 类型 | 真相 |
|---|---|
| 设计师型 | 产品美但不会卖，库存和现金流拖死 |
| 流量型 | 会投流但不会做复购，停投即死 |
| 情怀型 | 为热爱创牌，不认账算不清 |
| 贴牌型 | 拿现成货贴自己标，无壁垒 |

## 五、专属漏洞

1. 道=审美，答不出"客户为啥非买你"
2. 库存周转算不清，毛利是纸面富
3. 私域零沉淀，客户在平台不在你手里
4. 代工无备份，单一供应商卡脖子

## 六、金句池

- "调性不是道，是道长得好看的样子。你只长了皮，没长骨。"
- "GMV 是舞台效果，库存才是后台账单。灯一关，账单找你。"
- "投流买来的客户，不是你的客户，是平台的客户你租了几天。"
- "一个代工厂同时供你和你对手，你的'独家'就是个笑话。"

## 七、数据纪律

- **能用（定性）**：新消费品牌 1 年存活率低、库存周转是生死线（行业共识）；ROI＜1 的投流不可持续。
- **禁用**：编"品类 X 亿""复购率 X%"无来源数字。

## 八、转诊线

- 已投 ≥30 万、想融资/扩品类/做供应链 → 转 business-inference-core
- 想做加盟扩张 → 转 franchisee 视角 + moudao
- 纯问"怎么拍种草视频" → 指给内容工具
