# 非生意场景的五层映射（职场 / 学业 / 家庭）

> 本 skill 的主场是"生意"，但用户常拿职场、学业、家庭的事来问（该不该辞职、考研还是工作、要不要支持家人创业）。五层照样能用，只是每一层换问法。
> **铁律：不许把生意话术硬套。** "客户""成交""复购"这类词，在职场/学业/家庭场景必须换成对应说法，否则用户一听就知道你在套模板。
> **加载时机**：用户问的明显不是生意（跳槽 / 考学 / 家庭分工），且识别不到具体 persona 时，加读本文件。

---

## 一、五层在三种场景里的问法

| 层 | 生意场景 | 职场场景 | 学业场景 | 家庭场景（替家人问 / 共同决策） |
|---|---|---|---|---|
| **道** | 你图什么？卖什么给谁 | 你到底想要什么（钱 / 成长 / 稳定 / 自由） | 你读这个是为了什么（真热爱 / 逃避就业 / 要个出路） | 你真正担心、真正想要的是什么 |
| **法** | 怎么做到·怎么赚钱 | 你靠什么持续拿到你要的（能力 / 关系 / 位置） | 你靠什么把这条路走通（分数 / 作品 / 人脉） | 钱怎么出怎么分、亏了谁担责 |
| **术** | 怎么获客、怎么成交 | 怎么让机会找到你、怎么谈成一个 | 怎么准备、怎么申请、怎么考 | 怎么跟对方把话说清 |
| **器** | 用什么工具 | 你手里有什么能带走的资产（作品 / 口碑 / 技能） | 你手里有什么筹码（基础 / 时间 / 资源） | 你在这事里是什么角色 |
| **势** | 现在是不是时候 | 现在跳的窗口是不是开着的 | 现在考 / 转的时机对不对 | 现在是不是做这件事的时候 |

## 二、场景专属雷区

- **职场**：别把"跳槽"当"生意转型"拆。员工不是在"做生意"——他的道是"我想要什么样的生活"，不是"卖什么给谁"。
  - 禁词：获客 / 成交 / 复购 → 换成"机会怎么来、怎么谈成、能不能持续"。
  - 高频真问题：**逃避型跳槽**（在哪儿都不舒服，换一家还是不舒服）、**工龄幻觉**（待得久≠值钱）、**可迁移资产为零**。
- **学业**：别灌输"一切都为了赚钱"。考研可能真为了学术，别用"法 = 怎么赚钱"硬套 → 换成"怎么把这条路走通"。
  - 高频真问题：**盲从考研**（不知道为啥考，只因为同学都考）、**海投简历**（投一百份没有一家回）、**证书囤积**（考了一堆证还是没方向）。
- **家庭**：先问"你是操盘人吗"（见 SKILL 边界段"替别人问"规则）。旁观者别硬拆对方的五层——拆的是别人的生意，他执行不了。

## 三、总判定怎么迁移

生意版判定是"能跑 / 不能跑 / 先补 X"。三种场景迁移：

| 场景 | 三档判定说法 |
|---|---|
| 职场 | 该走 / 该留 / 先攒够【X 资本】再说 |
| 学业 | 该考（上）/ 该就业 / 先补【X】再决定 |
| 家庭 | 支持但先把【X】谈清 / 别急着投 / 先搞清谁担责 |

**共同底线**：顺序永远 道→法→术→器→势，势保持独立；结论必须给明确立场，不和稀泥；给你个建议是：照样带"具体对象 + 时间 + 判定"三件套。
