# 视角：餐饮老板（实体餐饮 · 聚焦供应链 / 食安 / 后厨 / 消费降级）

> 适用：开餐厅、奶茶、小吃、正餐的老板。通用实体门店逻辑见 `perspective-store.md`，本篇只补餐饮专属的"后厨+供应链+食安+预制"四件事，不重复门店通用死法。

## 一、五层长相（餐饮专属）

| 层 | 真实长相 | 典型误区 |
|---|---|---|
| 道 | 替谁解决"吃顿好/省事/社交"的哪一类需求？ | 把"我菜好吃"当道，没想清替谁、什么场景 |
| 法 | 盈利模型：食材成本率、人效、翻台、损耗、外卖占比 | 只看营收不看食材损耗和后厨浪费 |
| 术 | 选址、大众点评/抖音、私域复购、外卖运营 | 只会等客，不会做复购和私域 |
| 器 | 供应链、中央厨房、后厨SOP、食安体系、会员系统 | 器=厨师脑子，厨师一走味就变 |
| 势 | 消费降级、预制菜冲击、平台抽佣、商圈转移 | 还在赌"位置好就稳" |

## 二、典型死法（餐饮专属）

- **道层死法 · 自嗨口味** → 老板觉得好吃，目标客群不认，复购为零
- **法层死法 · 损耗失控** → 食材损耗+外卖平台抽佣吃掉毛利，账面流水好实际亏
- **术层死法 · 私域零沉淀** → 全靠新客和平台流量，没有回头客机制
- **器层死法 · 厨师即系统** → 配方和火候长在厨师脑子里，人一走就崩
- **势层死法 · 逆降级涨价** → 消费降级期还提客单价，客人先跑

## 三、势从哪来

1. **消费降级势**：客单价敏感，性价比和小份化是趋势。
2. **预制菜势**：上游预制抹平"现炒"壁垒，纯靠手艺的壁垒在塌。
3. **平台抽佣势**：外卖综合成本 20-25%，你是给平台打工。
4. **食安合规势**：一次食安事故可让一家店直接关停。

## 四、归因分类

| 类型 | 真相 |
|---|---|
| 厨师创业型 | 菜好但不会算账和获客 |
| 加盟型 | 买个牌子和配方，不会本地化运营 |
| 情怀型 | 为热爱开店，不认账 |
| 流量型 | 会做抖音但不会做复购 |

## 五、专属漏洞

1. 食材成本率/损耗算不清，毛利是幻觉
2. 后厨无 SOP，依赖个别厨师
3. 食安合规裸奔，一次事故归零
4. 复购机制为零，每天重新创业

## 六、金句池

- "你菜好吃，但客人只来一次，等于你每天重新开业。"
- "食材损耗+平台抽佣，先把你账面毛利吃一半，你还觉得流水不错。"
- "后厨长在厨师脑子里，厨师一走，你的味就死了。"
- "消费降级你还涨价，客人比你先跑。"

## 七、数据纪律

- **能用（store.md 已核实）**：2025 餐饮人均 33 元降 23.6%（红餐）；外卖综合成本 20-25%、60% 门店亏损（市场监管总局调研）；闭店率 22.66%（NCBD）。本篇复用，不重编。
- **禁用**：编"翻台率 X""食材成本率 X%"无来源数字，标「假设」。
