# 不同生意，道法术器势的权重不同

## 先认清楚（最重要）

目前的人群弹药（perspective-*.md）是按**"谁在做"**分的。但"卖货 / 卖服务 / 卖课 / 卖加盟 / 卖软件"这些**生意模式**不同，五层的**瓶颈层和假势高发区**也不同。识别到用户的生意模式，先读这张表，知道该重点拆哪层、哪层最容易藏假象。

> 这不是新框架，是"道法术器势"在同一门生意上的不同落点。模式判断 + 人群判断一起用，拆得更准。

## 模式 × 层权重矩阵

| 生意模式 | 最易塌的层 | 最该盯的层 | 典型死法（薄弱点映射） |
|---|---|---|---|
| **卖实体货 / 零售 / 餐饮** | 法（算不清回本线、毛利） | 器（库存 / 供应链 / 流程） | 压货压死现金流、一天卖 20 杯撑不起房租 |
| **卖服务 / 咨询 / 交付** | 道（伪道最多：为证明自己干） | 器（交付靠人、不可复制） | 越做越累、病一场生意停、没沉淀资产 |
| **卖内容 / 课 / 知识付费** | 势（红利退潮最快） | 法（复购 / 转介绍） | 一锤子买卖、九块九到处是、信任崩 |
| **卖加盟 / 代理 / 快招** | 法（单店模型是假的） | 道（割韭菜嫌疑） | 快招收割反噬、加盟商不赚钱跑路 |
| **卖软件 / SaaS / AI 工具** | 道（伪需求最多） | 术（获客贵、留存低） | 烧钱没留存、PMF 没验证就扩张 |
| **卖体验 / 文旅 / 线下空间** | 势（区域饱和、平台依赖） | 器（流程标准化难复制） | 一店旺多店死、被平台抽干流量 |

## 用法（识别到模式后）

1. 先看这张表，圈出"最易塌的层"——拆的时候重点盯它。
2. 看"最该盯的层"——破局指令优先落这层。
3. "典型死法"对应到五层薄弱点，直接点名。

## 跨模式共性（都要查）

- 不管什么模式，**道伪**（跟风/证明自己/面子）一律判不能跑。
- 不管什么模式，**一单一结没年框**= 没借到组织的势，迟早被替代。
- 不管什么模式，**流程全在老板一个人身上**= 器弱，规模上不去。

## 和人群弹药的关系

模式判断和人群判断是两张筛子：
- 人群（perspective-*.md）告诉你"这类人常踩的坑"（如美业女性老板的伪道、非遗大师的作品变现困局）。
- 模式（本文件）告诉你"这门生意本身的结构性坑"（如卖课必查复购、卖货必查回本线）。
- 两者叠加，薄弱点总结会非常准。
