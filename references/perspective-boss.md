# 视角：企业主（老板本人 · 拥有一家公司、操心整盘）

> 适用：自己当老板、名下有家公司（不限行业），要操心从战略到发工资整盘的人。区别于 `perspective-internal-ai`（企业内部被派去推 AI 的中层——那是为别人打工）和 `perspective-store`（只开一家实体店的老板）。这拨人是"老板本人视角"，看的是整盘生意的命。

## 一、五层长相（老板眼里的道法术器）

| 层 | 这拨人的真实长相 | 典型误区 |
|---|---|---|
| 道 | 公司到底替谁解决什么不可替代的问题？很多老板答"我做 XX 行业的"——这是行业，不是道 | 把"公司在"当道，没想清公司存在的独特价值 |
| 法 | 整盘盈利模型：毛利、人效、现金流、回本周期、复购率 | 只看营收流水，不看净利和现金流，账上永远紧 |
| 术 | 获客（销售体系/渠道/转介绍）+ 成交（商务/方案） | 全靠老板个人关系和酒桌，团队接不住 |
| 器 | 团队、系统、供应链、客户资产、管理工具 | 器=自己一个人，公司长在老板脑子里 |
| 势 | 行业周期、政策、技术替代、人才供给往哪走 | 还在用十年前的打法，不知赛道已变天 |

## 二、典型死法映射

- **道层死法 · 价值模糊** → 啥都接、啥都做，没有"只我最能打"的那一点，越做越散
- **法层死法 · 现金流盲区** → 账面有营收没现金，一遇欠款就断流，靠信用卡/民间借贷续命
- **术层死法 · 老板即销售** → 老板一不来生意就停，公司离了老板转不动
- **器层死法 · 人即系统** → 流程全在老人脑子里，老人一走客户和Know-how一起没
- **势层死法 · 逆周期硬扛** → 行业下行还扩产能、还加人，撞上淘汰潮

## 三、势从哪来

1. **技术替代势**：AI 正在把"老板靠经验拍板"的部分活儿拉平，不会用的被会用的碾压。
2. **人才流动势**：95 后不愿进传统老板的"狼性"体系，招人越来越难、人力成本刚性上升。
3. **合规加压势**：税务、社保、环保、数据合规收紧，灰色空间越来越小。
4. **客户迁移势**：采购决策从"关系"转向"性价比+数字化体验"，老关系失效。

## 四、归因分类

| 类型 | 真相 |
|---|---|
| 关系型 | 靠老板个人关系起家，关系一断公司就垮 |
| 勤奋型 | 老板比谁都忙，但忙在救火不在建系统，公司长不大 |
| 跟风型 | 看风口啥热做啥，没有主心骨，永远在切换赛道 |
| 技术型 | 产品过硬但销售弱，好东西卖不出去 |

## 五、专属漏洞（诊断重点看）

1. **道 ≠ 行业**：问"公司替谁解决什么不可替代的问题"，答"我做 XX 的"= 道层空洞
2. **不看现金流**：只有营收账没有现金账，欠款一多就裸泳
3. **老板即瓶颈**：所有关键动作离不开老板本人，老板不在公司停转
4. **不敢放权**：怕手下做错，凡事自己扛，公司卡在老板精力上限
5. **被伪咨询收割**：花大钱请"大师"做战略/股权激励，落地为零

## 六、金句池（沙龙直接用）

- "你不是老板，你是公司最大的那个员工——离了你，公司明天就停。"
- "营收是面子，现金流是里子。你只盯面子，里子早就漏了。"
- "公司长在你脑子里，等于没长在公司身上。"
- "啥都接的老板，等于啥都不精。你以为叫灵活，客户叫你杂牌。"
- "请大师做战略，不如先把昨天那笔欠款收回来。"

## 七、数据纪律

- **能用（定性）**：中小企业平均寿命约 3 年、5 年存活率＜10%（工信部口径，可引）；90% 创业死在现金流（普遍共识）。
- **谨慎**：具体行业"闭店率/亏损面"数字口径混乱，沙龙慎用，要引就引权威口径并标注年份。
- **禁用**：编"我们这个行业 X 亿规模""老板平均赚 X 万"这类无来源数字。

## 八、转诊线

- 已投入 ≥30 万且有员工、涉及股权/融资/跨行业扩张 → 超出 3 分钟轻量自检，转 business-inference-core 深度推演（同仓库）
- 想做品牌化/连锁扩张 → 转 moudao 做扩张规划
- 纯问"怎么写招聘JD""怎么算税" → 不归本 skill，指给对应工具
