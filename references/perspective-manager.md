# 视角：团队领导者（中层管理 · 带团队/向上管理/空降/夹心层）

> 适用：带团队的中层管理者——部门经理、总监、team leader、空降兵、夹在老板和员工之间的"夹心层"。区别于 `perspective-boss`（老板本人操心整盘）：中层不带整盘，但带的是一线产出和一群人的状态。管理层的道法术器和个人贡献者完全是两套。

## 一、五层长相（管理层眼里的道法术器）

| 层 | 这拨人的真实长相 | 典型误区 |
|---|---|---|
| 道 | 你要的是"被团队喜欢"还是"带着大家打胜仗"——两个只能选一个 | 想两个都要，最后变成谁都不满意的老好人 |
| 法 | 管理是杠杆：团队产出应该大于你自己单干。团队 5 个人干不出你 3 倍的活，管理就是反杠杆 | 把"管理者"当职级不是当职能，干活还是自己上 |
| 术 | 怎么让下属服你：打胜仗+分利益。不是请客吃饭搞关系 | 用饭局和客气换服从，换来的只是表面客气 |
| 器 | 机制替代你传话：流程、例会、看板，还是全在你微信里吼 | 人肉传声筒+人肉闹钟，你一休假团队就瘫痪 |
| 势 | 你这个位置的可替代性：公司还需不需要这个层？向上还有没有位置？ | 只看位置不看势，组织一调整第一个被合并的就是中间层 |

## 二、典型死法映射

- **道层死法 · 老好人** → 谁都不敢得罪，谁都不敢管，团队一团和气一事无成
- **法层死法 · 反杠杆** → 下属的活你全接，自己天天加班，团队还说你抢功
- **术层死法 · 保姆式管理** → 教一遍不会教两遍，最后变成"放着我来"——你成了团队最强的执行、最差的领导
- **器层死法 · 全在微信里** → 任务靠私聊、进度靠问、资料靠翻记录，你一休假全乱
- **势层死法 · 夹心层幻觉** → 老板压任务你原样往下传，员工有怨你原样往上递——传声筒没有势，随时可换

## 三、行业困局（这行到底卡在哪）

夹心层（上面压指标、下面不服从）、管理成反杠杆（自己干得越多，团队越弱）、老好人带不出战斗力、空降没根基（没信任就动不了手）。管理的本质是杠杆——你亲自干的活越多，说明杠杆越差。

## 四、大众困局（这拨人常见的误会）

- "自己干最快"——错。你干得越多，团队越废。
- "大家喜欢我就是好领导"——错。要被喜欢，就打不了胜仗。
- "空降先立威"——错。先做成一件小事，再动大手术。

## 五、势从哪来

1. **组织扁平化**：中间管理层在被系统性压缩，公司越来越不需要"传话的人"，只需要"扛结果的人"。
2. **管理工具化**：协同工具+AI 让"信息汇总、进度跟踪"型管理动作贬值，管理者的价值在决策和背责，不在同步信息。
3. **结果可量化**：管理层越来越难用"我很忙""团队很稳定"交代，数字说话的时代，扛不住数字的位置说没就没。
4. **年轻团队的权威迁移**：95 后 00 后不认职级只认本事——你能带我打胜仗、教我东西，我才服。

## 六、归因分类

| 类型 | 真相 |
|---|---|
| 技术转管理 | 手艺放不下，下属干活你看不上，最后自己干到死 |
| 空降兵 | 没根基就烧火，三把火烧完盟友全没了 |
| 夹心层 | 把自己当传声筒，其实是翻译层——翻译错了才是你的责任 |
| 老好人 | 用"人好"换安全感，团队用"平庸"回报你 |

## 七、专属漏洞（诊断重点看）

1. **管理杠杆自检**：你这季度亲自干的活，占团队总产出的几成？超三成，你就不是管理者，是高级执行。
2. **怎么接烂摊子**：新团队不服你——别先立威，先打一个具体的胜仗（一个小目标+明明白白的分钱），赢一次比说十次管用。
3. **怎么跟老板要资源**：别诉苦（"人手不够"），带方案去（"加一个人，我能把 X 指标从 A 做到 B，不加就只能保 A"）。老板不为难买单，为数字买单。
4. **怎么裁人**：拖着的"不忍心"才是真残忍——对走的人不干脆，对留的人不公平。
5. **下属不服怎么办**：一对一面谈一次，问"你觉得咱们团队最该改的一件事是啥"。答不上来的，是不关心；答得上但你装没听见的，不服是你自找的。

## 八、金句池（沙龙直接用）

- "管理者拼的是让团队产出最高，活干得最好那是标兵。"
- "老好人带不出队伍，只能带出巨婴。"
- "夹心层这名头不对，你是翻译层——翻译错了才是你的责任。"
- "你舍不得裁的那种'不忍心'，是对留下的人最大的不公平。"
- "请客吃饭换来的服从，一顿饭就过期。"

## 九、数据纪律

- **能用（定性）**：组织扁平化趋势、管理层压缩、结果导向考核普遍化（均为普遍共识）。
- **禁用**：编"某公司管理层占比 X%""中层平均在职 X 年"——口径混乱，慎引。

## 十、转诊线

- 涉及裁员决策、组织架构重组、跨部门政治 → 超出轻量自检，找 HRD 和有经验的过来人当面聊
- 想自己当老板（整盘视角）→ 转 `perspective-boss` / `perspective-founder` 视角
- 情绪持续低落、失眠绝望 → 走 `emotional-companion.md` 危机边界，暖着转介，不硬拆
