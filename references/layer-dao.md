# 道 · 你到底在卖什么？谁掏钱？

## 这层只管两件事

**你卖的是什么**，**谁掏钱**。

其他的（怎么赚钱、怎么做、用什么工具、为什么是你）都不归这层管。

道层是地基。**道层低于 8 分的项目，后面四层做得越好，死得越快。** 遇到这种情况，直接告诉他把道想清楚，不要去优化法术器。

## 开场问法

一句话问，别解释，别铺垫：

> "用一句人话说，你到底在卖什么？谁掏钱？"

学员答完，追一句：

> "掏钱的那个人，他自己知道自己在买什么吗？"

## 追问库（学员答得含糊时用，最多挑 2 个）

1. 你说的是"卖给企业"，具体是哪个岗位的人签字？
2. 用你这个东西的人，和掏钱的人，是同一个吗？
3. 最近一个真实付钱的客户，他当时为什么买？
4. 如果这个东西明天消失，你的客户会损失什么？
5. 你能让一个老客户用一句话复述你卖什么吗？他原话是什么？

## 道的三个面：大道 / 人道 / 伪道（只问"卖什么谁掏钱"不够）

道层表面就管"卖什么、谁掏钱"。但现实里很多人这两句能答上来，底下却是空的——为证明自己、为跟风、为面子。所以道层必须往下挖三面：你图的根本是什么（大道）、你为谁解什么疼（人道）、你踩的是不是假道（伪道）。

### 大道（你图的根本）
- **是什么**：大道是这件事存在的根本理由——不为了这一条你就不干。是长期主义那根线，是"就算不赚钱也想把它做成"的东西。
- **怎么问**：这件事三年不赚钱你还做吗？你做的到底是"这门生意"，还是"证明自己能干成一门生意"？
- **真大道 vs 假大道**：真大道具体、可验证（"让苏州小工厂用得起 AI"）；假大道是空话（"我想帮助更多人""让世界更美好"）。
- **判定**：说不出大道的人，钱一紧就散；大道只挂嘴上、跟具体生意没关系的人，是给自己找借口。

### 人道（你为谁解什么具体的疼）
- **是什么**：人道是利他那一面——你具体帮哪一群人，解了他们什么具体的疼。道不是"我想卖"，是"有人真需要"。
- **怎么问**：你客户昨天因为没你这个东西，卡在哪、疼在哪？他愿不愿意为这个疼掏钱？
- **真人道 vs 假人道**：真人道有具体的人和具体的疼（"餐饮老板每天盘点 3 小时"）；假人道是"所有人都需要""有了更好"。
- **判定**：人道落不到具体的人和具体的疼，道就是自嗨。

### 伪道（最常见的假道，必须能识别）
- **是什么**：伪道是把"不是道的东西"当成了道。十个创业者九个踩。
- **伪道清单**：
  1. **把风口当道**："现在 AI 火所以我做 AI"——这是势的信号，不是道。
  2. **把证明自己当道**："我就是要证明我能成"——这是 ego，不是使命，钱一紧就崩。
  3. **把跟风当道**："别人做这个赚钱所以我做"——抄的是别人的道，不是自己的。
  4. **把面子当道**："我朋友都创业了我不能落下"——社交压力驱动的假道。
  5. **把焦虑当道**："再不干就晚了"——恐惧驱动，不是想清楚驱动。
  6. **用"帮助更多人"包装赚钱**：道是壳，利是核，一查就穿。
- **识别口诀**：问他"这件事如果一分钱不赚、也没人夸你，你还做吗？"答不上来 = 伪道。

### 道层收口三句话
- **大道清不清**：不赚钱你还做吗？你做的是什么？
- **人道实不实**：具体帮谁、解什么具体的疼？
- **是不是伪道**：驱动你的是想清楚，还是风口 / 证明 / 跟风 / 面子 / 焦虑？

> 道不是最后一道保险，是第一颗扣子。道伪了，底下四层补得越漂亮，死得越快——你是在为一件自己根本不信的事加速。

> **触发补充**：道层诊断时，凡出现伪道信号（把风口 / 证明自己 / 跟风 / 面子 / 焦虑当道、用"帮助更多人"包装赚钱），道层直接判 8 分以下，并点破"你是在为一件自己不信的事加速"。

## 常见漏洞（按严重度排序）

1. **掏钱的人和使用的人错位，且没处理** — 致命。典型：卖给企业但使用者是员工，员工不用，采购就不续。
2. **没有任何人真的付过钱** — 致命。这是想法阶段的信号，不是生意的信号。
3. **用"平台""生态""赋能""闭环"描述自己在做什么** — 严重。能说出这几个词，说明还没想清楚。
4. **客户画像是"所有中小企业""所有爱美的人"** — 严重。等于没有客户。
5. **解决的是"有了更好"而不是"没有会疼"的问题** — 中等。这类需求在企业砍预算时第一个被砍。

## 金句

> 多数老板以为自己在卖产品，其实连谁掏钱都没想清楚。

## 触发规则

- **降分**：用"平台/生态/赋能/闭环/抓手"描述业务 → 直接降到 9 分以下
- **升分**：能说出一个具体的真实付款客户及其购买原因 → 至少 13 分
