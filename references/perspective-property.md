# 视角：房产经纪（中介 / 门店 / 独立经纪人）

> 适用：做二手房、租房、新房的经纪人和门店老板。这拨人卡在"政策周期+端口费+获客成本+信任崩"里，最容易把"带看多"当"生意稳"，把"平台给的客源"当"自己的客户"。

## 一、五层长相

| 层 | 真实长相 | 典型误区 |
|---|---|---|
| 道 | 你替买卖双方解决什么"确定性成交/避坑"的价值？ | 把"我房源多"当道 |
| 法 | 盈利模型：佣金率、成交周期、端口费占比、复购（转介绍） | 只看成交不算端口费和获客成本 |
| 术 | 获客（端口/抖音/社区）、带看、逼定、售后 | 全靠砸端口费买客，停砸没客 |
| 器 | 客源系统、房源库、个人IP、合作网络 | 器=一个端口账号，被平台卡 |
| 势 | 政策周期、利率、供需、平台抽佣 | 误把"行情好"当"我有本事" |

## 二、典型死法

- **道层死法 · 房源即道** → 以为房源多就赢，没想清替客户解决什么决策价值
- **法层死法 · 端口吞噬** → 端口费+获客成本吃掉佣金，成交越多越像给平台打工
- **术层死法 · 复购裸奔** → 全靠新客，转介绍无机制，客户买完就失联
- **器层死法 · 账号依赖** → 客源长在端口账号里，号一禁生意归零
- **势层死法 · 逆周期硬扛** → 下行期还猛砸端口，成交萎缩反被成本拖死

## 三、势从哪来

1. **政策周期势**：限购/利率/税费一变，成交量剧烈波动，收入随周期坐过山车。
2. **端口抽佣势**：端口费和平台流量费是固定成本，行情差时最致命。
3. **信任崩势**：行业整体信任度低，个人 IP 信任是少数护城河。
4. **平台化势**：大平台直营和线上化压缩传统中介生存空间。

## 四、归因分类

| 类型 | 真相 |
|---|---|
| 端口型 | 靠砸钱买客，停投即死 |
| 社区型 | 扎根片区靠口碑，但难放大 |
| IP型 | 做抖音个人号，流量不稳 |
| 店东型 | 开门店雇人，人效失控 |

## 五、专属漏洞

1. 端口费/获客成本不算进成交账，毛利是幻觉
2. 客户零沉淀，买完即失联无转介绍
3. 客源长在平台账号，无自有资产
4. 政策预案为零，周期一变收入断崖

## 六、金句池

- "端口费是你的房租，成交佣金是你的工资，扣完你才发现是在给平台打工。"
- "客户买完房就失联，等于你每次都重新创业。"
- "行情好时你以为自己牛，行情差时才知道是风把你吹起来的。"
- "客源长在别人账号里，号一禁，你明天就失业。"

## 七、数据纪律

- **能用（定性）**：房地产经纪高度依赖政策周期与平台端口（行业共识）；端口费是主要成本项。
- **禁用**：编"佣金 X 万""成交周期 X 天"无来源数字，标「假设」。
