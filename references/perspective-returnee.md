# 视角：海归 / 留学生（回国就业/创业/接班）

> 适用：留学回国的人——就业、创业、移民犹豫、家族企业接班。这拨人的核心问题：**花了真金白银和几年时间，回来发现市场的定价和自己心里的定价不一样**。

## 一、五层长相（海归眼里的道法术器）

| 层 | 这拨人的真实长相 | 典型误区 |
|---|---|---|
| 道 | 你回来是因为机会，还是因为躲——自我欺骗最贵 | 用"国内机会多"解释"国外没留下"，自己都信了 |
| 法 | 留学的投入产出账：花了多少万，计划几年回本——多数人不敢算 | 把留学当投资算账，算完心态先崩 |
| 术 | 国内信息差怎么补：实习、校友、内推 vs 只在招聘软件上海投 | 人在国外时没攒国内实习，回来校招窗口已关 |
| 器 | 带回来什么：语言、视野、方法论、人脉 vs 只有一张文凭 | 以为文凭是敲门砖，其实文凭已经通货膨胀 |
| 势 | 海归光环的贬值速度、行业匹配度、回国窗口期 | 用五年前的认知评估现在的市场 |

## 二、典型死法映射

- **道层死法 · 光环幻觉** → 以为海归身份值钱，面试发现和国内应届生同池竞争
- **法层死法 · 投入产出失衡** → 花了几百万，回来月薪几千——账一算人先崩
- **术层死法 · 信息差** → 错过校招窗口、不懂国内招聘节奏、简历按国外格式写
- **器层死法 · 两头空** → 国外人脉用不上，国内人脉没攒，文凭之外带不回任何东西
- **势层死法 · 两头漂** → 国内国外都定不下来，漂的时间比选错的成本还高

## 三、势从哪来

1. **海归光环贬值**：供给暴增+国内教育崛起，"出国=优秀"的默认假设在失效——本事比身份保值。
2. **出海与新全球化**：中国企业出海潮——懂两边语言、两边规则的人反而稀缺，这是新溢价点。
3. **窗口期**：毕业即回国赶校招，是最顺的路径；漂两年再回来，身份和窗口双输。
4. **家族接班**：民营企业接班潮——有现代管理训练的海归是稀缺资源，但要过"说话没人听"这一关。

## 四、归因分类

| 类型 | 真相 |
|---|---|
| 就业型 | 最主流——校准薪资预期是第一关 |
| 创业型 | 用国外看到的模式回国复制——先验证国内需求是否存在 |
| 移民犹豫型 | 最耗人——两头比较永远没答案，要设决策截止日 |
| 接班型 | 最稳也最难——带的是现代管理，碰的是家族人情 |

## 五、专属漏洞（诊断重点看）

1. **投入产出账**：把留学总花费写下来，除以目标年薪，算出回本年限。不敢算的就是答案。
2. **薪资预期校准**：市场给海归的定价已经回归能力本位——先查目标城市目标岗的真实区间，再谈期望。
3. **校招窗口**：应届身份+秋招春招节奏——错过这段，好岗位的门就关了一半。
4. **校友网络激活**：校友是这个群体最被低估的器——求职、创业、信息差，全靠它。
5. **接班的话事权**：空降接班先要的不是改革，是信任——先做成一件小事，再动大手术。

## 六、金句池（沙龙直接用）

- "海归的光环在贬值，带回来的本事才保值。"
- "留学是消费不是投资，你非要按投资算账，心态先崩。"
- "两头漂的时间成本，比选错更贵。"
- "文凭已经通货膨胀，作品和经历才是硬通货。"
- "回国最好的时间是毕业时，其次是现在——但别漂成第三年。"

## 七、数据纪律

- **能用（定性）**：海归供给增加、薪资溢价回归、出海人才需求上升（普遍共识）。
- **禁用**：编"海归平均薪资 X""回国就业率 X%"——年份、国家、专业差太远，编了就是制造焦虑。
