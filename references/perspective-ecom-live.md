# 视角：电商直播（主播 / 商家自播 / 达人）

> 适用：靠直播间/短视频带货吃饭的人——主播、达人、商家自播团队老板。这拨人最容易被 GMV 幻觉骗，把"场观"当"收入"、把"平台给的流量"当"自己的客户"。

## 一、五层长相

| 层 | 真实长相 | 典型误区 |
|---|---|---|
| 道 | 你替观众解决什么"决策省心/捡漏/陪伴"的需求？ | 把"我能说会道"当道 |
| 法 | 盈利模型：毛利、退货率、投流ROI、净GMV | 只看GMV不看退货后净利 |
| 术 | 选题、话术、投流、排品、私域承接 | 全靠平台推流，不接私域 |
| 器 | 直播间、供应链、中控、CRM、达人资源 | 器=一个主播人设，人塌号没 |
| 势 | 平台算法风向、品类周期、达人红利窗口 | 误把"平台推我"当"我有势" |

## 二、典型死法

- **道层死法 · 人设即道** → 没想清替观众解决什么，靠吼和福利留人，人设一崩全没
- **法层死法 · 退货刺客** → GMV 漂亮，退货率 50%+，到手净毛利为负
- **术层死法 · 投流依赖** → 不投没流量，投了不赚钱，被平台双向收割
- **器层死法 · 单一主播** → 号绑在一个人脸上，离婚/翻车/跳槽即归零
- **势层死法 · 追红利** → 哪个品类火跟哪个，永远在追尾巴

## 三、势从哪来

1. **算法风向势**：平台把流量从达人转向店播/货架，决定获客成本。
2. **退货文化势**：直播"冲动下单+运费险"让退货率远高于传统电商。
3. **达人红利势**：个人 IP 窗口短，平台造星也造替代品，不沉淀等于租流量。

## 四、归因分类

| 类型 | 真相 |
|---|---|
| 叫卖型 | 会逼单不会选品，退货吃掉利润 |
| 供应链型 | 货好但不会播，流量浪费 |
| 投流型 | 会买量不会做复购，停投即死 |
| 达人型 | 有粉不会变现，接不到匹配货 |

## 五、专属漏洞

1. 把 GMV 当收入，不看退货后净利
2. 客户在平台不在微信，私域零沉淀
3. 号绑人脸，无矩阵无备份
4. 选品无标准，靠感觉上架

## 六、金句池

- "GMV 是舞台效果，退货单才是后台账单。灯一关，账单找你。"
- "平台推给你的流量，不是你的客户，是你租了几天的过客。"
- "一个号绑一张脸，等于把公司押在一颗会塌的牙上。"
- "你会逼单但不会选品，等于会收钱但不会挑货，仓库全是退回来的。"

## 七、数据纪律

- **能用（定性）**：直播电商平均退货率显著高于传统电商（行业共识 30%-60% 区间波动，引需标年份口径）；投流 ROI＜1 不可持续。
- **禁用**：编"我这个类目复购率 X%"无来源数字，标「假设」。

## 八、转诊线

- 已投 ≥30 万做供应链/矩阵、想融资 → 转 business-inference-core
- 纯问"怎么写直播话术" → 指给内容工具
- 想做品牌化 → 转 perspective-brand
