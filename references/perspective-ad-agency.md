# 视角：广告 / 营销公司老板

> 适用：开广告、营销、创意、代运营公司的老板。这拨人是"卖脑子"的，最容易被"比稿拿单"和"人力密集"拖死，把"案例好看"当"公司有壁垒"。

## 一、五层长相

| 层 | 真实长相 | 典型误区 |
|---|---|---|
| 道 | 替客户解决什么"确定性增长/转化"的结果？ | 把"我会做创意"当道 |
| 法 | 盈利模型：人效、毛利率、回款周期、复购（年框） | 只看合同额不看人效和回款 |
| 术 | 拿单（比稿/关系/转介绍）、交付、续约 | 全靠比稿和老板关系，续约无机制 |
| 器 | 团队、方法论、案例库、工具链 | 器=几个核心人，人走方法走 |
| 势 | 甲方预算周期、AI 替代、平台玩法变迁 | 误把"甲方离不开我"当势 |

## 二、典型死法

- **道层死法 · 创意即道** → 沉迷作品集，没想清替客户交付什么可量化结果
- **法层死法 · 人效崩** → 项目靠堆人，毛利被人力吃光，越做越累
- **术层死法 · 比稿依赖** → 单子靠比稿拿，赢率低且白干，无稳定获客
- **器层死法 · 方法不沉淀** → 每次从零做，核心人一走重来
- **势层死法 · 被AI替代焦虑** → 基础活被 AI 抹平，溢价能力塌

## 三、势从哪来

1. **预算周期势**：甲方 marketing 预算随经济波动，先砍的就是外部代理。
2. **AI 替代势**：文案/设计/投放基础活被 AI 拉平，纯执行类代理贬值。
3. **效果归因势**：甲方从"买创意"转向"买确定性增长"，说不清 ROI 的代理被弃。
4. **关系势**：决策人一换，关系清零。

## 四、归因分类

| 类型 | 真相 |
|---|---|
| 创意型 | 作品牛但交付弱，回款难 |
| 关系型 | 靠老板人脉，人一走单飞 |
| 执行型 | 接代运营苦活，毛利薄 |
| 数据型 | 会投流不会做品牌，被当乙方工具 |

## 五、专属漏洞

1. 人效算不清，合同额掩盖亏损
2. 回款周期长，现金流紧
3. 方法论零沉淀，重复造轮子
4. 续约无机制，每年重新拿单

## 六、金句池

- "合同额是面子，人效是里子。你堆人交付，赚的是辛苦钱还倒贴。"
- "比稿赢了是运气，输了是白干，你拿命赌概率。"
- "甲方换个人，你的关系清零，你居然没备份决策链？"
- "AI 把你的基础活抹平了，你剩下的溢价，客户凭什么付？"

## 七、数据纪律

- **能用（定性）**：营销代理行业人效/回款是普遍痛点（行业共识）；甲方预算随周期波动。
- **禁用**：编"行业毛利率 X%"无来源数字，标「假设」。

## 八、转诊线

- 已投 ≥30 万、想融资/扩团队/做产品化 → 转 business-inference-core
- 纯问"怎么写方案PPT" → 指给内容工具
