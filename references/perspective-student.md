# 视角：大学生 / 应届生（就业/考研/考公/创业的十字路口）

> 适用：在校生（大三大四为主）和毕业一两年内的应届生。这拨人最大的特点：**手里只有时间，没有筹码**——所以每一层的问题都是"我现在攒什么"。

## 一、五层长相（学生眼里的道法术器）

| 层 | 这拨人的真实长相 | 典型误区 |
|---|---|---|
| 道 | 你到底要什么：就业、考研、考公、创业、出国——大四了还没选，就是全都要 | 别人考研我考研，把"随大流"当"安全" |
| 法 | 你的变现路径：第一份工作卖什么、卖多久、复购（成长）是什么 | 把"找到工作"当终点，其实是起点 |
| 术 | 怎么让机会找到你：实习、作品、内推、口碑 vs 海投简历 | 以为投简历是找工作的主要动作，其实投递环节最没溢价 |
| 器 | 带得走的：作品、技能、项目经历、人脉 vs 只有成绩单 | 攒了一抽屉证书，拿不出一个能给人看的东西 |
| 势 | 行业和岗位的四年周期：你入学时火的方向，毕业时可能已经在收 | 用高考填志愿时的认知，赌四年后的市场 |

## 二、典型死法映射

- **道层死法 · 盲从** → 全班都考研你就考，考上发现还是不知道要干啥
- **法层死法 · 终点幻觉** → 以为拿到 offer 就上岸，入职三年才发现第一份工作把自己锁死了
- **术层死法 · 海投** → 网申一百家，面试三家，一个真offer——投递是最没差异化的动作
- **器层死法 · 证书囤积** → 考一堆证，没有作品、没有项目、没有拿得出手的经历
- **势层死法 · 刻舟求剑** → 四年前的热门方向，毕业时岗位已经在缩

## 三、势从哪来

1. **AI 冲击入门岗**：初级文案、初级设计、基础翻译、数据录入——应届生最大的就业池在被拉平。
2. **学历通胀**：同一岗位的学历门槛逐年抬升，本科的议价空间在缩。
3. **校招窗口**：应届身份是大多数好岗位的唯一入口，错过成本极高。
4. **个体势**：会做自媒体、能接单、有作品的应届生，正在绕过传统招聘直接变现。

## 四、归因分类

| 类型 | 真相 |
|---|---|
| 就业型 | 目标最清晰，但容易只看薪资不看成长复利 |
| 逃避型 | 考研考公是缓兵计——不是不能考，是别骗自己"考上了就好了" |
| 探索型 | 最健康也最容易漂——探索要有截止日 |
| 创业型 | 最勇敢也最脆弱——没被社会验证过就 all in，九死一生 |

## 五、专属漏洞（诊断重点看）

1. **第一份工作怎么选**：平台、成长、钱三样，最多占两样。三样都想要的 offer 不存在。
2. **考研是不是逃避**：问自己"不考我打算干嘛"。答不上来，就是逃避。
3. **应届身份怎么用**：校招、实习留用、内推——这三条路的优先级远高于社招海投。
4. **免费劳动力识别**：实习没工资可以，学不到东西+纯打杂不行。
5. **试错成本错觉**：以为年轻就可以随便试——时间是本金，随便试是亏本金。

## 六、金句池（沙龙直接用）

- "第一份工作卖的是你的将来，不是你的现在。"
- "海投一百份简历，不如一个拿得出手的作品。"
- "考研不是逃避，'以为考上了就好了'才是。"
- "你攒了一抽屉证书， HR 只问你：你做过什么？"
- "年轻是本钱，但本钱亏完了就只剩年轻。"

## 七、数据纪律

- **能用（定性）**：应届生就业竞争加剧、AI 替代基础岗位、校招是主要入口（普遍共识）。
- **禁用**：编"今年应届生平均薪资 X""某专业就业率 X%"——年份、地域、口径差太远，编了就是制造焦虑。
