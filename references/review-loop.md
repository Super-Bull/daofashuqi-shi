# 测完一次，怎么跟踪（复盘闭环）

## 先认清楚（最重要）

自测是**快照**，生意是**演化**的。今天拆完五层，下个月道法术器势可能全变。所以自测不是一次性动作，是**每月一次的体检**。没有闭环，上次的破局指令执行没执行、哪层涨了哪层还塌，全靠记忆，等于白测。

## 闭环三步

### 第 1 步 · 今天（测完立刻做）
把这次的「薄弱点总结 + 破局行动指令 + 每条判定标准」抄到**一个固定地方**（手机备忘录 / 一张纸 / 一个文档），不要散在聊天记录里。
- 判定：三条指令 + 三条判定标准，一句话不差地写下来了。

### 第 2 步 · 7 天后（看执行）
逐条核对破局指令的判定标准达成没：
- 达成了 → 打勾，写"XX 做到了"。
- 没达成 → 写原因（是动作不对，还是这层根本不是当前阶段该打的——见 stage-model.md）。
- 判定：至少 1 条打勾，才算这轮没白测。

### 第 3 步 · 30 天后（重测）
重跑一遍五层自测（用下面这张简版卡），对比：
- 哪层分涨了？（证明破局指令打对了层）
- 哪层还塌？（可能源头在更上层，见 layer-linkage.md）
- 更新「薄弱点总结 + 破局指令」。
- 判定：能说出"X 层比上月高了，因为做了 Y"= 闭环成了。

## 30 天自测简版卡（直接复用）

```
道：有人真掏钱吗？不赚钱我还做吗？（一句）
法：一单净赚多少？有复购吗？（一句）
术：这个月新客从哪来？几步成交？（一句）
器：我不在场，这摊事能转吗？（一句）
势：凭什么是我？窗口什么时候关？（一句）
最弱层：______  本月破局动作：______（带判定标准）
```

## 话术

> 自测不是交作业，是装个体检仪。你今天测完不跟踪，下个月还是凭感觉。每月花 10 分钟过这张卡，比年年报课有用。

## 和别的模块怎么配合

- 重测发现某层反复塌 → 用 `layer-linkage.md` 查是不是被上层拖的。
- 重测发现阶段变了（0→1 变 1→10）→ 用 `stage-model.md` 调整破局聚焦点。
- 重测后要做完整报告 → 走 `report-template.md` + `experiments.md`。
