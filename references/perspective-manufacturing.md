# 视角：制造业代工转品牌 / 出海老板

> 适用：有产能、有工厂、给大牌贴牌/代工，现在想做自己的品牌或出海。客单价高、决策重，值得单独一套。对应你之前"代工转品牌"的真实案例。

## 一、五层长相（这拨人眼里的道法术器）

| 层 | 真实长相 | 典型误区 |
|---|---|---|
| 道 | 凭什么消费者选你而不是大牌？你的差异化是什么 | 以为"质量好价格低"就是道，这是代工思维 |
| 法 | 品牌定位 + 渠道结构（线上/线下/跨境） | 还按"接单生产"逻辑做品牌，没有渠道打法 |
| 术 | 营销获客、内容种草、招商 | 只会埋头生产，不会面向 C 端说话 |
| 器 | 供应链本是优势，但常变成思维陷阱 | 以为"我有工厂"就等于"我会做品牌" |
| 势 | 出海窗口、国货红利、AI 降获客门槛 | 错过品类红利期，或盲目出海踩合规坑 |

## 二、典型死法映射

- **道层死法 · 贴牌思维做品牌** → "我质量跟大牌一样，凭什么卖便宜"——消费者不认代工身份
- **法层死法 · 不会建渠道** → 有货没路，天猫/抖音/跨境都不会玩，货压在仓库
- **术层死法 · 不会跟 C 端说话** → 厂长话术直接怼消费者，内容没人看
- **器层死法 · 供应链陷阱** → 产能越多越敢压货，库存把现金流压死
- **势层死法 · 逆红利周期** → 品类已过风口才进场，或出海踩关税/合规雷

## 三、势从哪来

1. **微笑曲线势**：纯 OEM 毛利率 <15%、甚至 <10%；ODM 约 20%；成熟自主品牌 40% 左右，高端超 50%（慈溪小家电调研，新华社瞭望东方周刊）。爬两端才有肉。
2. **AI 降门槛势**：白牌工厂用 AI 生成测评内容 + 小红书/抖音种草 + 私域，启动成本可低至 1.76 万（佛山家具厂案例），月净利 4.7 万、净利率 48%。
3. **出海窗口势**：OEM 净利润率 3-5%，海外自有品牌 12-18%，品牌溢价 30-200%（大数跨境）。
4. **国货红利势**：乖宝宠物代工起家，自有品牌占比 41%→63%，毛利从 20-25% 升到 30-40%+。

## 四、归因分类

| 类型 | 真相 |
|---|---|
| 被动转型型 | 代工订单被客户压价/流失，不得不做品牌，但没准备好 |
| 二代接班型 | 年轻一代想做自有品牌，会用新媒体，成功率高 |
| 盲目扩张型 | 产能起来了就压货做品牌，库存压死现金流 |
| 出海冲动型 | 听人说出海赚钱就冲，不懂当地合规和渠道 |

## 五、专属漏洞

1. **道层 · 代工思维**：把"质量好"当差异化，消费者无感
2. **法层 · 渠道空白**：只会生产不会卖，没有可复用的渠道打法
3. **术层 · C 端失语**：不会做内容、不会种草、不会讲品牌故事
4. **器层 · 库存陷阱**：产能越大越敢压，现金流断裂
5. **势层 · 合规盲区**：出海踩关税/认证/商标坑，钱没赚到先交罚款

## 六、金句池

- "你有工厂，不等于你会做品牌。工厂是成本中心，品牌是利润中心，这是两门生意。"
- "代工赚的是制造费，品牌赚的是溢价。你干了二十年最累的活，拿了最少的钱——这就是微笑曲线底部。"
- "质量跟大牌一样，凭什么卖便宜？消费者不认你的代工身份，他只认牌子。"
- "AI 把获客门槛打下来了，白牌工厂 1 万 7 千块就能起步——但你得先想清楚卖给谁。"
- "出海不是换个地方卖货，是换一套规则。不懂合规，钱没赚到先交罚款。"

## 七、数据纪律

- **能用**：OEM 毛利 <15%、ODM ~20%、自主品牌 40%+、高端 50%+（慈溪/网易）；OEM 净利 3-5%、海外自有品牌 12-18%、溢价 30-200%（大数跨境）；乖宝代工 20-25%→自有 30-40%+（三个皮匠）；白牌转型启动 1.76 万、净利 48%（头条案例）。
- **谨慎**：单厂个案（佛山/浙江）数据漂亮，但属个例，讲的时候说"有工厂跑通过"，别当普遍规律。
- **禁用**：把"代工占比超七成"说成"代工都赚不到钱"——慈溪数据明确"稳定运营自主品牌不足 20%"，是能力问题不是宿命。

## 八、转诊线

- 已投入 ≥100 万做品牌、团队 ≥10 人 → 超轻量自检，转 business-inference-core 或 moudao 做品牌战略
- 纯问"怎么注册海外商标""怎么开独立站" → 不归本 skill，指给工具
- 想拿政府转型补贴 → 指给政策查询，不在此框架内
