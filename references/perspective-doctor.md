# 视角：名医 / 知名医生（副主任及以上、有个人品牌意识）

> 适用：三甲/民营医院有声誉的医生、科室主任、想做个人 IP 或多点执业的名医。典型状态——号难约、患者多但患者管理粗放，想做科普获客但合规严、没时间。对应你社群里那批"专业强、时间贵、想做口碑但被行政和流量困住"的医生。

## 一、五层长相（这拨人眼里的道法术器）

| 层 | 真实长相 | 典型误区 |
|---|---|---|
| 道 | 治病救人+声誉，但没想清"我的道是诊疗不是运营" | 把"搞流量"当不务正业 |
| 法 | 靠医院平台，没设计个人品牌/多点执业模型 | 病人全在医院系统里，不在自己手里 |
| 术 | 靠口碑转介，不会做科普获客（合规严） | 想做号但怕说错话被投诉 |
| 器 | 患者在线下/医院系统，AI 辅助诊断/随访但合规 | 随访靠护士手工，效率低 |
| 势 | 医生 IP 化、患者教育需求大，合规科普是势 | 还在只坐诊，不做任何积累 |

## 二、典型死法映射

- **道层 · 排斥运营** → "我是大夫不搞这些"——但患者管理粗放，价值没放大。
- **法层 · 无个人资产** → 病人跟着医院走，离开平台就归零。
- **术层 · 不敢科普** → 怕说错被投诉，错失信任建设。
- **器层 · 手工随访** → 护士忙不过来，复诊漏掉。
- **势层 · 只坐诊** → 不做任何积累，时间全耗在门诊。

## 三、行业困局（这行到底卡在哪）

门诊量大没时间做患者管理、科普内容被平台限流、多点执业政策模糊。医生的稀缺是"诊断时间"，最贵的是他本人。AI 的价值是**合法辅助（写科普合规文案、管随访、做患者分层），把时间还给他看该看的病**——不是替他诊断。

## 四、大众困局（这拨人常见的误会）

- "我一个大夫搞什么 AI/运营"——错。AI 帮你管随访省出看诊时间。
- "做科普会被投诉"——错。合规科普（讲常识不承诺疗效）是势。
- "病人都在医院系统里"——错。离开平台你就联系不上他们。

## 五、势从哪来

1. **医生 IP 势**：患者认人，合规科普建立信任。
2. **随访势**：AI 管复诊提醒，降低失访。
3. **多点势**：政策放开，有个人品牌的医生能接更多。

## 六、归因分类

| 类型 | 真相 |
|---|---|
| 门诊吞噬型 | 时间全在门诊 |
| 科普想做型 | 想做但不敢/不会 |
| 多点意向型 | 想多点但没品牌 |
| 传承型 | 想带学生但没沉淀 |

## 七、专属漏洞

1. **道 · 排斥运营**：价值没放大。
2. **法 · 无资产**：病人跟医院走。
3. **术 · 不敢科普**：错失信任。
4. **器 · 手工**：随访漏。
5. **势 · 只坐诊**：不积累。

## 八、金句池

- "你最贵的是你的诊断时间，AI 帮你把随访和科普的活接了，你专心看该看的病。"
- "病人今天在你这看，明天就找不着了——不把关系留下来，你只是流水线上的工号。"
- "合规科普不是营销，是让患者少走弯路，也是让你被认出来的方式。"
- "离开医院平台你还能不能看诊？这个问题想清楚，再做品牌。"

## 九、数据纪律

- 本人群无特定权威数据，用户没说就标「假设」，不编门诊量/收入。

## 十、转诊线

- 纯问"科普怎么不违规" → 指给合规顾问。
