# 五层拆完，到底能跑不能跑

## 先认清楚（最重要）

拆完五层、打了分，必须给一个**明确的总判定**。不许和稀泥（"各有优劣视情况而定"= 没说）。这条是铁律 7 的落地版——光说"要给立场"不够，得有从五层推到结论的统一规则。

## 三档判定

| 档位 | 含义 | 你该说什么 |
|---|---|---|
| **不能跑**（立刻停/大改） | 道层伪或没人真掏钱，或道法双弱且势假 | "先别干，正道/正法。底下补得越漂亮，死得越快。" |
| **先补 X 再谈**（有条件） | 四层里有 1-2 层塌，但源头清晰 | "能跑，但得先打 X 层。打完再来看。"（给明确单层指令） |
| **能跑**（小步验证） | 道法稳、术器在跑、势有问题但窗口还在 | "方向对，给你最小验证动作，先跑通再放大。" |

## 判定推导链（AI 内部用，听众看不到）

按顺序走，命中第一条就停：

1. **道 < 8**（伪道 / 没人付过钱 / 用"赋能闭环"描述）→ **不能跑**，正道优先。
2. **道 ≥ 8 且 法 < 8** → **先补法**（算回本线、看复购）。
3. **道法 ≥ 8 且（术 < 8 或 器 < 8）** → **先补术/器**（跑通一单 / 资产化）。
4. **道法术器都 ≥ 8 且 势 < 8** → **能跑但卡势**（找生态位、算窗口关闭时间）。
5. **全 ≥ 8** → **能跑**，给放大动作（见 stage-model.md 对应阶段）。

> 补充：道 < 8 时总分再打 5 折（见 scoring.md）。势 < 8 但道法术器稳，是"能跑但别浪"。

## 输出话术模板（扎心但明确）

- 不能跑："你不是 X 不行，是你一直在补最底下那层，上面 Y 一层没碰。先把 Y 想清楚，底下补了也是给错误方向加速。"
- 先补 X："方向没问题，卡在 X 层。今天就能做的动作是……（带判定标准）。打完这层，剩下几层会自己松动。"
- 能跑："这摊事能跑。别急着放大，先把这个最小验证动作跑通：…… 跑通了再谈规模。"

## 和别的模块怎么配合

- 判定"先补 X"时，X 若是道/法 → 读 `layer-dao.md` / `layer-fa.md` 深挖；X 若是术/器 → 读对应 layer；卡势 → 读 `layer-shi.md`。
- 判定要结合阶段：同样"术弱"，0→1 期先补道法，1→10 期才轮到术（见 `stage-model.md`）。
- 联动拖累：若最弱层是被上层拖的，判定要追到源头层（见 `layer-linkage.md`）。
