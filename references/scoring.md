# 五层评分标准（每层 0-20 分，满分 100）

## 打分规则（先读）

1. 每层独立打分，五层之间不折算、不加权。
2. **打分依据是学员实际说出来的内容。没说到的不算分**，不许替学员脑补。
3. 落在两档之间取低档。
4. 学员答不上来的层 → 直接给该层最低档，并在报告里标「信息不足」。
5. 每层都有「降分触发」和「升分触发」，命中时按标注执行，优先于区间判断。

---

## 道（0-20）· 你到底在卖什么？谁掏钱？

| 分数 | 表现 |
|---|---|
| 17-20 | 客户能一句话复述你的价值，且有人主动替你转介绍 |
| 13-16 | 卖什么、谁掏钱、解决什么问题都清楚，且已经有人为此付过钱 |
| 9-12 | 三件事都清楚，但这个问题不够痛（客户可买可不买） |
| 5-8 | 能说清卖什么，但掏钱的人和使用的人不是同一批，且没处理好这个错位 |
| 0-4 | 说不清卖什么，或说不清谁掏钱 |

- **降分触发**：用"平台""生态""赋能""闭环""抓手"描述业务 → 直接降到 9 分以下
- **升分触发**：能说出一个具体的真实付款客户及其购买原因 → 至少 13 分

---

## 法（0-20）· 这事怎么持续赚钱？

| 分数 | 表现 |
|---|---|
| 17-20 | 有可复制的体系，换个人也能跑，且规模越大单位成本越低 |
| 13-16 | 每个客户的获客成本、毛利、复购率都算得清，且数字健康 |
| 9-12 | 收入结构清晰，但没算过获客成本或毛利 |
| 5-8 | 有复购，但靠老板个人关系维持，不成体系 |
| 0-4 | 只有一次性收入，没有复购、没有壁垒 |

- **降分触发**：说"先做大规模再考虑赚钱" → 降到 9 分以下
- **升分触发**：能说出复购率的具体数字且 >30% → 至少 13 分

---

## 术（0-20）· 下一步具体做什么？

| 分数 | 表现 |
|---|---|
| 17-20 | 已跑过至少一轮真实验证，拿到数据，并据此调整过计划 |
| 13-16 | 下一步动作明确指向验证关键假设，且有判定标准和截止日 |
| 9-12 | 有优先级，但动作是"做事"不是"验证假设" |
| 5-8 | 有动作清单，但没优先级、没截止日 |
| 0-4 | 只有想法，没有下一步动作 |

- **降分触发**：动作清单里"学习/调研/准备"占比超过一半 → 降到 9 分以下
- **升分触发**：能说出"我用 X 天验证 Y，如果出现 Z 我就放弃" → 至少 13 分

---

## 器（0-20）· 靠什么做出来、做完留下什么？

| 分数 | 表现 |
|---|---|
| 17-20 | 工具/数据/流程本身构成壁垒，别人抄不走 |
| 13-16 | 关键流程有工具固化，数据可沉淀、可交接，新人能照做 |
| 9-12 | 工具能撑住当前业务，但没沉淀成资产 |
| 5-8 | 有工具，但互相不通，靠人肉搬运 |
| 0-4 | 全靠人肉，没有工具 |

- **降分触发**：说"都在我脑子里""都在微信里" → 降到 9 分以下
- **升分触发**：能说出核心流程已固化、新人照着能做 → 至少 13 分

---

## 势（0-20）· 为什么是现在？凭什么是你？

| 分数 | 表现 |
|---|---|
| 17-20 | 势能自我强化：做得越多，优势越大，而不是越累 |
| 13-16 | 时机窗口明确，且有独占的生态位 |
| 9-12 | 有独特资源，但跟当前要做的事关系不大 |
| 5-8 | 有一点先发优势，但不可持续 |
| 0-4 | 说不清为什么是现在，也说不清凭什么是自己 |

- **降分触发**：说"因为现在这个很火" → 降到 9 分以下
- **升分触发**：能说出"只有我能做"的具体原因，且这个原因别人短期抄不走 → 至少 13 分

---

## 总分算法（重要：体现"上下关系"，不是累加）

**总分 = 五层里最低的那一层 × 5**（百分制）。

- 五层独立打分后，取最低分那一层，乘以 5 作为总分。
- 例：道 16 / 法 8 / 术 4 / 器 12 / 势 6 → 最低「术」4 分 → 总分 20/100。
- 含义：生意卡在最弱那一层，最强那层再高也拉不动总分。这跟框架铁律一致——五层是上下关系，从下往上补无效。

**道层低于 8 分时，总分再打 5 折**，并在报告顶部加警示：「道层没想清楚之前，后面四层做得越好，死得越快」。

| 总分（瓶颈分） | 结论（报告里必须用这个口径） |
|---|---|
| 80-100 | 最弱那层也够硬，去找钱、去找人 |
| 60-79 | 有一层是短板，补这一块就能跑 |
| 40-59 | 结构性短板，先重塑最弱那一层 |
| 20-39 | 主要矛盾没解决，现在投入越多亏越多 |
| 0-19 | 建议先别投钱，回去想清楚最弱那层（尤其道层） |
