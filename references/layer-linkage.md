# 五层不是孤岛：谁在拖死谁

## 先认清楚（最重要）

五层拆开看，每一层都能打个分。但真实生意里，层与层是**连着的**——上面塌了，下面补得越漂亮，死得越快（这条铁律已经锁死）。

除了"道决定法"这种单向关系，还有几种**典型的拖累模式**。学员问"我到底该先改哪层"时，不是五层一起补，是找到**拖累链的最源头那一层**打它。

## 六种拖累模式（带识别信号 + 破局落点）

### 1. 道伪 → 法必歪
- **信号**：道是跟风/证明自己/面子驱动（见 layer-dao.md 伪道清单），法层自然设计成"快钱一次性"——因为底层自己都不信，只想赶紧证明"我能成"。
- **表现**：法层只有一次性收入、没复购、没算过回本线。
- **破局**：先正道，别优化法。法怎么补都救不了伪道。

### 2. 法空 → 术乱
- **信号**：商业逻辑没想清（怎么持续赚不知道），术就变成"什么都试"——今天发短视频、明天搞社群、后天做投放，永远在准备。
- **表现**：术层一堆动作但没转化、没闭环。
- **破局**：先算回本线（一单净赚多少、要几单回本），法清楚了术才有靶心。

### 3. 术弱 → 器白搭
- **信号**：获客成交没跑通，再好的工具也是摆设——你 AI 用得再溜，没有客户来，工具只是高级花瓶。
- **表现**：器分高但没客户、没成交记录。
- **破局**：先手工跑通一单（哪怕嘴+微信），再上工具放大。

### 4. 器弱 → 术被锁死
- **信号**：流程全在人脑里、客户在微信聊天记录里，术想规模化也扩不动——你不在场生意就停。
- **表现**：病三天店瘫、朋友照着做不出杯、没可复用资产。
- **破局**：先把流程写下来、把客户沉淀到可触达的地方，术才能放大。

### 5. 势无 → 前面白干
- **信号**：道法术器都稳，但窗口不对 / 没生态位 / 说不清凭什么是你。
- **表现**：答不出"凭什么是我"、把风口当势。
- **破局**：找"生态位一句话" + 算清窗口什么时候关，不是继续内卷获客。

### 6. 势假 → 误判全部
- **信号**：把风口当势（"AI 火所以我做"），会反过来**掩盖道伪**——用"趁势"合理化自己根本没想清的道。
- **表现**：开口就是追热点、用趋势替代理由。
- **破局**：先拆道（伪道信号一查就穿），再谈势。势救不了伪道。

## 联动诊断法（怎么用）

给学员拆完五层后，做一步**拖累链追溯**：

1. 找出最弱的那层（通常就是"薄弱点总结"点名的层）。
2. 顺着往上追：**它是自己塌的，还是被上一层拖塌的？**
3. 一直追到"源头那层"——那才是该先打的地方。

> 话术：你不是五层都有问题，你是「X 层」塌了，把「Y 层」一起拖死了。先打 X，Y 自然缓过来；你一层一层补，补到 Y 还是死的。

## 常见错配（顺带点破）

- 0→1 的人拼命学 AI 工具（器），本质是道法没过——补错层了。
- 10→100 的人还在抠获客话术（术），本质是势没卡住——补错层了。
- 见 `references/stage-model.md` 确认他处在哪个阶段。
