# 视角：咨询 / 猎头 / 企业服务老板

> 适用：开咨询公司、猎头公司、企业培训/代运营等服务型公司的老板。这拨人卖的是"人脑+关系"，最容易被"人均产值"和"知识不沉淀"卡死，把"我认识谁"当"公司有壁垒"。

## 一、五层长相

| 层 | 真实长相 | 典型误区 |
|---|---|---|
| 道 | 你替客户解决什么"确定性决策/人选/增长"的结果？ | 把"我懂行"当道 |
| 法 | 盈利模型：人均产值、毛利率、项目周期、复购（年框） | 只看合同额不看人均产值 |
| 术 | 获客（转介绍/标杆案例）、交付、续约 | 全靠老板关系和老客户，无体系 |
| 器 | 顾问团队、方法论、案例库、知识库 | 器=几个核心人，人走知识走 |
| 势 | 甲方预算、AI 替代、自建团队趋势 | 误把"甲方依赖我"当势 |

## 二、典型死法

- **道层死法 · 经验即道** → 靠个人阅历接单，没想清交付什么可量化结果
- **法层死法 · 人均崩** → 项目靠堆高级顾问，毛利被人力吃光
- **术层死法 · 关系依赖** → 单子靠老板人脉，老板不管就断粮
- **器层死法 · 知识不沉淀** → 每次从零做方案，核心人一走重来
- **势层死法 · 被自建替代** → 甲方成熟后自建团队，外包需求消失

## 三、势从哪来

1. **预算周期势**：甲方咨询/猎头预算随经济波动，先砍外部服务费。
2. **AI 替代势**：基础调研/报告/初筛被 AI 拉平，纯信息差服务贬值。
3. **自建替代势**：甲方做大后把核心能力内化，外包转自建。
4. **标杆势**：一个标杆案例能带来滚雪球转介绍，没有则永远在冷启动。

## 四、归因分类

| 类型 | 真相 |
|---|---|
| 人脉型 | 靠老板关系，人一走单飞 |
| 专家型 | 个人强公司弱，无法放大 |
| 产品型 | 试图标准化却交付注水 |
| 项目型 | 接一个做一个，无复利 |

## 五、专属漏洞

1. 人均产值算不清，合同额掩盖亏损
2. 知识库零沉淀，重复造轮子
3. 续约无机制，每年重新拿单
4. 核心人单点依赖，离职即失血

## 六、金句池

- "合同额是面子，人均产值是里子。你堆高手交付，赚的是辛苦钱还倒贴。"
- "知识长在几个人脑子里，人一走，公司回到创业第一天。"
- "甲方壮大后第一件事就是自建团队，你的外包需求自己没了。"
- "你靠关系拿单，关系在老板身上，老板一休假公司就断粮。"

## 七、数据纪律

- **能用（定性）**：专业服务行业人均产值是核心指标（行业共识）；甲方预算随周期波动。
- **禁用**：编"人均产值 X 万""行业规模 X 亿"无来源数字，标「假设」。

## 八、转诊线

- 已投 ≥30 万、想做产品化/SaaS化/融资 → 转 business-inference-core
- 纯问"怎么写咨询方案" → 指给内容工具
