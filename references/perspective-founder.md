# 视角：小团队创业者（2-10 人 · 招人/合伙/分钱/从 0 到 1）

> 适用：带着 2-10 个人的小团队往前跑的人——刚招了第一个员工、拉兄弟合伙、纠结分钱、从"自己干"往"带人干"过度的创业者。区别于 `perspective-opc`（一个人单干）和 `perspective-boss`（已成规模的公司老板）：这拨人最危险——比单干多了一堆成本，比公司少了一套机制。

## 一、五层长相（小团队眼里的道法术器）

| 层 | 这拨人的真实长相 | 典型误区 |
|---|---|---|
| 道 | 你是想"当老板"还是想"做成这件事"——想当老板的，会招一堆人陪你演 | 为了"像个公司"租办公室、招行政、设部门，把现金流演空 |
| 法 | 人效账：10 个人干不出你 1 个人 10 倍的活，招人就是亏 | 只算"业务多了要人手"，不算"这个人多久能自己养活自己" |
| 术 | 先有单再招人：客户在哪、凭什么持续来 | 业务还没验证就扩张，用招人掩盖"不会找客户" |
| 器 | 公司不靠你也能转的程度：流程、客户资产、交接成本 | 公司全靠创始人一张嘴，人一病全停 |
| 势 | 窗口期多长、对手多快、你凭什么是你 | 用"我们很努力"对抗"别人有资源"，努力不是护城河 |

## 二、典型死法映射

- **道层死法 · 老板cosplay** → 公司还没赚钱，"总"的派头先齐了——办公室、头衔、组织架构，全是给外人看的
- **法层死法 · 人效崩盘** → 10 个人围着 2 个能挣钱的人转，人均产值盖不住工资，半年烧光本金
- **术层死法 · 先摆摊后找客** → 产品研发仨月，客户一个没谈——用执行上的勤奋掩盖商业上的懒惰
- **器层死法 · 创始人即系统** → 客户只认创始人、决策只在创始人脑子里，招的人全是"手"不是"腿"
- **势层死法 · 窗口误判** → 别人融资你烧自己的，别人占住了坑你还在打磨，等你完美了，市场没你的位了

## 三、势从哪来

1. **小团队的效率势**：船小掉头快，大厂半年决策你三天就试——这是你唯一的势，别丢。
2. **AI 抹平人力差**：以前要 5 个人干的活，现在 1 个人+AI 能干——小团队"人多"不再是优势，"人精"才是。
3. **合伙风险势**：经济下行期合伙散伙率飙升，兄弟式合伙的账越拖越难算。
4. **人才市场势**：小公司招人的逻辑变了——留不住人就别重培养，用项目制、外包、兼职把固定成本变可变成本。

## 四、归因分类

| 类型 | 真相 |
|---|---|
| 技术型 | 东西做得好，客户找不来——死于不会卖，不是死于产品差 |
| 销售型 | 单子接得飞起，交付留不住人——死于交付，不是死于没单 |
| 兄弟型 | 不好意思谈钱、谈退出、谈分工——死于账不清，不是死于感情 |
| 融资型 | 拿钱当本事、把估值当收入——死于把借来的钱当赚来的 |

## 五、专属漏洞（诊断重点看）

1. **人效账（最重要）**：团队月薪总和 ÷ 月净利润，比值超过 3 就是警报。创始人自己先算这笔账，算完再决定招不招人。
2. **分钱机制**：股权平均分（33/33/33 或 50/50）是埋在土里的雷——决策时没人拍板，散伙时没人让步。该谈"动态股权"：出钱、出力、出资源各算各的账。
3. **第一个员工怎么招**：别招"能力强"的，招"能独当一面的"——小团队养不起需要你带的人，第一年每个人都要自己养活自己。
4. **合伙引入时机**：先共事，再合伙。没一起干过三个月就谈股权的，等于没见过面就结婚。
5. **什么时候该裁人**：连续两个季度，产出盖不住成本，且没有改进路径——拖着的每一秒都在花你的钱。裁人要快、要合法、要一次性给够赔偿。

## 六、金句池（沙龙直接用）

- "没验证完的商业模式，招人只是把成本放大。"
- "股权平均分那天，就注定有一天要撕破脸。"
- "公司小的时候靠人情，长大靠机制——中间隔着一笔笔没算清的账。"
- "你不是缺人，你是缺一个能自己养活自己的人。"
- "想当老板的人招一群人陪他演，想成事的人招一个人顶一片天。"

## 七、数据纪律

- **能用（定性）**：小团队平均寿命短、合伙散伙率高、人效是小团队生死线（普遍共识）。
- **禁用**：编"初创企业 X 年内倒闭率 X%""合伙纠纷占 X%"——口径混乱，慎引，要引就引权威口径标年份。

## 八、转诊线

- 已投入 ≥30 万、涉及股权设计/融资/多股东利益 → 转 business-inference-core 深度推演，本 skill 不硬跑
- 股权/合伙协议具体条款 → 找律师，别用 AI 生成
- 想清楚要一个人单干 → 转 `perspective-opc` 视角重拆
- 创始人长期高压、失眠、情绪濒临崩溃 → 走 `emotional-companion.md` 危机边界，暖着转介——创业者的心理健康是比现金流更早崩的那根弦
