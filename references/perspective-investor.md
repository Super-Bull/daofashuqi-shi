# 视角：投资人（VC / 天使 / FA / 产业投资）

> 适用：投钱给别人的人——机构投资人、个人天使、FA、产业战投。这拨人的"生意"是自己的投资组合：他们天天拆别人的道法术器势，但轮到自己，五层问的是另一套东西。

## 一、五层长相（投资人眼里的道法术器）

| 层 | 这拨人的真实长相 | 典型误区 |
|---|---|---|
| 道 | 你的钱图什么：财务回报、产业布局、个人名声——混着投最危险 | 说是战略投资，其实想要财务回报，最后两头没占到 |
| 法 | 回报结构：基金期 vs 个人钱，DPI/IRR，退出通道（IPO/并购/回购） | 用基金的方法投个人的钱，节奏全错 |
| 术 | 项目从哪来：FA 推、熟人介绍、扫赛道——好项目不流通 | 等 FA 送上门，送上门的多是别人挑完的 |
| 器 | 尽调能力、投后赋能、文档和风控体系 vs 只有钱 | 只会给钱，不会看人，更不会帮 |
| 势 | 赛道窗口、周期位置、退出环境（IPO 松还是紧） | 在退出最紧的时候重仓，周期错了全白搭 |

## 二、典型死法映射

- **道层死法 · 目标混乱** → 战略、财务、人情混着来，复盘时说不清这笔为什么投
- **法层死法 · 退出无门** → 只想着怎么进，没想怎么出，钱变成"长期股东"
- **术层死法 · 项目饥渴** → 怕错过，FA 一推就投，一年十个项目九个坑
- **器层死法 · 赋能幻觉** → 投后天天给项目"指点江山"，帮倒忙还刷存在感
- **势层死法 · 逆周期重仓** → 赛道最热、估值最高时冲进去，接的是最后一棒

## 三、势从哪来

1. **退出环境**：IPO 节奏、并购市场活跃度，决定你的钱几年能出来。
2. **周期位置**：资本寒冬里才有便宜价格，热钱涌入时好项目也贵。
3. **AI 重构**：大量"AI+"项目是旧酒新瓶，真结构和真需求的没几个。
4. **产业协同势**：有产业资源的投资人，议价能力和退出通道都强于纯财务投资人。

## 四、归因分类

| 类型 | 真相 |
|---|---|
| 财务型 | 目标最纯，但容易在"怕错过"里动作变形 |
| 战略型 | 为产业布局服务，但容易用战略给自己的误判找借口 |
| 人情型 | 兄弟项目、校友项目——最难看清的恰恰是这种 |
| 玩票型 | 钱不多当交学费，问题是学费交不出方法论 |

## 五、专属漏洞（诊断重点看）

1. **个人资产配置比例**：拿身家的几成在投？超三成，投资人当不成，当赌徒。
2. **"明星项目"识别**：名气大 ≠ 能退出。问三句：收入结构、真实盈利、上一轮谁在接。
3. **投后角色错位**：你当顾问还是当老板？项目需要的是资源和耐心，不是指挥。
4. **FA 话术拆解**："这个赛道很热""好几个机构在抢"——翻译过来就是"贵，且不一定好"。
5. **人情项目的防火墙**：亲兄弟也要按机构流程走，没有文档的"信任投资"最后人财两空。

## 六、金句池（沙龙直接用）

- "好项目不流通，流通的都是别人挑完的。"
- "用基金的方法投个人的钱，等于用大炮打蚊子，还赔了炮。"
- "投后赋能四个字，一半是帮倒忙。"
- "只想着怎么进、没想怎么出的钱，不叫投资，叫被套。"
- "赛道最热的时候，也是你最该冷静的时候。"

## 七、数据纪律

- **能用（定性）**：创投退出以 IPO 和并购为主、早期项目失败率高（均为普遍共识）。
- **禁用**：编"某赛道融资 X 起""天使投资回报 X 倍"——口径混乱且极易过时，说了就是误导。

## 八、转诊线

- 具体项目估值、条款设计、回购谈判 → 找律师和财务顾问，别拿 AI 的话下注
- 基金 LP/GP 结构、合规备案 → 专业机构，本 skill 不接
- 重仓单项目 ≥30 万且影响家庭现金流 → 走 `verdict.md` 给立场，但明确这是配置决策不是生意自检
- 连续亏损、失眠绝望 → 走 `emotional-companion.md` 危机边界，暖着转介
