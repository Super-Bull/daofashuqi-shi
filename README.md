# 道法术器势 · 全领域商业模式辅助专家

用「道法术器势」五层框架，把任何人正在做的事一层一层拆开看：每层哪里做得好、哪里薄弱、具体该怎么改。全程大白话，听得懂。

**人格铁律：毒舌但暖的过来人。** 客观不迎合——不夸、不哄、不空安慰，但承认感受；说人话，禁 AI 味；每条建议今天就能做、带判定标准。先接人，再拆事；每次结束留回访钩子——这是长期陪伴，不是一次性诊断。

不联网、不查行业数据、不做多专家战略推演、不写商业计划书。用户只扔一句话、信息不全也能接住。

## 适合谁用

- **大厂人**：纠结走留、转型、副业、35 岁（光环 / 期权 / 螺丝钉化三专属坑）
- **职场人**：跳槽 / 转岗 / 35 岁 / 被裁 / 该不该离职
- **团队领导者**：中层带团队 / 向上管理 / 空降 / 夹心层
- **副业者**：选副业 / 评估副业 / 副业转正
- **小团队创业者（2-10 人）**：招人 / 合伙 / 分钱 / 从 0 到 1
- **投资人**：VC / 天使 / FA / 产业投资（看项目也看自己的组合）
- **大学生 / 应届生**：就业 / 考研 / 考公 / 创业的十字路口
- **导演 / 影视制作**：广告片 / 宣传片 / 短片 / 短剧（项目制无复利）
- **程序员 / 技术人**：独立开发 / 接单 / 转型 / 35+（能做出 ≠ 能卖出）

- **跨境电商卖家**：亚马逊 / 独立站 / Temu / TikTok Shop（单件全账 / 封店生存 / 独立站资产）
- 企业内 AI 转型推动者、数字化负责人
- 实体门店、代工厂转品牌、加盟 / 区域代理创业者
- **专业 / 高净值人群（已沉淀专属弹药）**：传统制造业观望型、美业女性老板、保险、律师、医美、高校老师、微商、名医、公务员、科研人员、证券银行金融

## 怎么用

1. 把这个 `daofashuqi-shi` 目录作为 skill 装进你的 Agent（WorkBuddy 等支持 skill 的客户端）。
2. 在对话框里直接说一句自己的情况，例如：「我在苏州开奶茶店一年，一天卖 20 杯，不赚钱」「我在大厂五年想走走不了」「我想搞个副业不知道干啥」。
3. skill 先接一句（点破你处境的真难处），再用「道法术器势」拆一遍，末尾给总判定 + 薄弱点总结 + 今天的动作（每条带判定标准）+ 一句"七天后来跟我说结果"。
4. 不依赖任何表格，不需要先打分。

## 框架速览

| 层 | 大白话问题 | 塌了会怎样 |
|---|---|---|
| 道 | 你图什么？（你的本心·初心） | 方向错了，后面全白干 |
| 法 | 怎么做到？怎么赚钱？（商业逻辑） | 赚一次是运气，不是生意 |
| 术 | 怎么获客？ | 永远在准备，从不开始 |
| 器 | 用什么工具？（工具） | 人一走，资产归零 |
| 势 | 现在是不是时候？（趋势·天时地利人和） | 风口一来，大部队进场你就没了 |

五层是上下关系，不是并列。分析顺序永远 道 → 法 → 术 → 器 → 势；「势」是独立维度，不接在「器」之后。

## 全栈自测增强模块（横向补全）

纵向五层 + 52 份人群弹药解决"拆得透"。下面十个模块解决"连得起来、测得准、跟得上、有人味儿"——补全全栈自测的短板：

- 层间联动 / 拖累诊断 → `references/layer-linkage.md`（哪层在拖死哪层，破局只打源头）
- 阶段论 → `references/stage-model.md`（0→1 / 1→10 / 10→100，先判阶段再定破局聚焦点）
- 总判定机制 → `references/verdict.md`（拆完五层推"能跑 / 不能跑 / 先补 X"）
- 生意模式 × 层权重 → `references/business-models.md`（卖货 / 服务 / 课 / 加盟 / 软件 / 文旅，瓶颈层不同）
- 死亡信号红线 → `references/red-flags.md`（各层致命红线一张表，自查距死多远）
- 复盘闭环 → `references/review-loop.md`（测完 7 天 / 30 天怎么跟踪）
- AI 成败案例库（按道法术器势归类）→ `references/ai-cases.md`（真实 AI 翻车 = 五层里某层塌了，给学员对照）
- **语言纪律** → `references/tone-language.md`（AI 味禁用词表 / 敷衍词表 / 反迎合纪律 / 毒舌但暖的过来人人格，每次回复必过）
- **情绪陪伴** → `references/emotional-companion.md`（接住→命名→转身三步法 / 温度边界 / 七日之约回访钩子 / 心理危机转介红线 / 迷茫 vs 危机判别）
- **非生意场景五层映射** → `references/scene-mapping.md`（职场 / 学业 / 家庭场景的五层问法迁移 + 场景雷区 + 判定迁移）
