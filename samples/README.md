# 实测样例

四类典型客群的真实对话样例（讲师自测 + 学员用前先看效果）。每个文件含「用户原话输入 + skill 完整回复」，按格式锁死的"道→法→术→器→势 → 薄弱点总结 → 破局行动指令"展开。

## 速览

| # | 场景 | 客群 | skill 关键判断 | 破局根因 |
|---|---|---|---|---|
| 01 | 婚庆跟拍两年，想做短视频又一直不动 | 苏州个体户 | 道层没定（不知道客户为什么选你），补得越漂亮死得越快 | 【道】 |
| 02 | 被上班逼出来想做 OPC 赚钱 | AI 爱好者 / OPC | 道层是"逃"不是"被需要"——写不出具体客户就不许辞职 | 【道】 |
| 03 | 公司不景气，培训还是招人？ | 企业小老板 | 这是术器二选一，根在道法空；先点燃内部小年轻，再决定外部 | 【道】 |
| 04 | 老公 35 岁被裁做 AI 创业，3 个月 0 收入 | 中年妻子（家属视角） | 老公用创业逃避上班；给家庭能做的边界动作 | 【道】 |

四个场景最弱层都是【道】——验证框架的核心论点：**90% 的生意死在"图个啥"没想透**，下面四层补得再漂亮也救不回来。

## 怎么看

每份样例都分三段：
1. **用户输入** — 模拟一个真实人的口语描述
2. **skill 回复** — 严格按"道法术器势、势独立最后、每层一句 ✅/⚠️、末尾薄弱总结 + 破局指令"展开
3. **示范了什么** — 给讲师/开发者看的拆解点（顺序锁死、薄弱不展开、指令带判定标准、主要矛盾唯一）

## 复刻 / 自测建议

- 拿样例里的"用户输入"覆盖成你自己的生意描述，直接喂给装好的 skill。
- 对比 skill 给你拆的结果和样例里拆的，看是不是同一套骨架——同骨架即格式稳。
- 如果某一层你拿不准，可以打开 `references/layer-{dao,fa,shu,qi,shi}.md` 看那层的标准动作库。
