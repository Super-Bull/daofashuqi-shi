# 实测样例

十份真实场景的「用户原话输入 + skill 完整回复」——讲师自测用，学员装好 skill 前先看效果。按输出格式呈现：**接住一句 → 一句话总评 → 总判定 → 道→法→术→器→势（势独立最后）→ 评分条 → 薄弱点总结 → 今天的动作 → 回访钩子**。

> **关于评分条（2026-10-15 起新增，默认输出）**：五层进度条 + 瓶颈分（最弱层 × 5；道层 < 8 再打 5 折），格式与五条护栏见 SKILL.md「评分条」章节。
> **本目录的同步情况**：只有 **01** 已按最新格式补上评分条（当示范用）；02/03/04/07/09/10 是评分条上线前录的，正文未含评分条；05/06/08 只出边界动作（不拆 / 转诊），本来就不需要评分条。
> **学格式请以 SKILL.md 的输出模板 + 示例为准**（两处都含评分条），或直接看 01。

## 速览

| # | 场景 | 客群 | skill 关键判断 | 破局根因 |
|---|---|---|---|---|
| 01 | 婚庆跟拍两年，想招人又怕没单 | 苏州个体户 | 道层没定（说不清客户为什么选你），招人和短视频补得越漂亮死得越快 | 【道】 |
| 02 | 被上班逼出来想做 OPC 赚钱 | AI 爱好者 / OPC | 道层是"逃"，没想过"被谁需要"——写不出具体客户就不许辞职 | 【道】 |
| 03 | 公司不景气，AI 培训还是招人？ | 企业小老板 | 这是术器二选一，根在道法空；先点燃内部小年轻，再决定外部 | 【道】 |
| 04 | 老公 35 岁被裁做 AI 创业，3 个月 0 收入 | 中年妻子（家属视角） | 老公用创业逃避上班；给家庭能做的边界动作，不越界改他的道 | 【道】 |
| 05 | 服装批发八年，睡不着，不知道该听谁的 | 倾诉型用户 | 没得到拆解许可前不硬跑框架——先听，再问"挑毛病还是先聊聊" | 不启动 |
| 06 | 道法术器势是谁提出来的？ | 纯知识问答 | 框架词 ≠ 触发拆解，直接答，不启动框架 | 不启动 |
| 07 | 便利店 + 抖音带货 + AI 培训三摊并行 | 多生意并行 | 一次只给一个主要矛盾——先定"先拆哪一摊" | 【道】 |
| 08 | 投 50 万建产线，要不要跨行业 + 拉合伙人 | 超范围转诊 | 重信号全中（≥30万/企业级/多方利益）——拆洞 + 最小验证 + 转诊，不给终局结论 | 转诊 |
| 09 | 字节五年，32 岁，想走走不了 | 大厂人 | 光环错当本事、单源现金流；走留不是问题，"走出去还值不值"才是 | 【器】 |
| 10 | 副业看了几个月，课买三门，零客户 | 副业者 | "学习型准备"是假动作——用准备逃避选择，用付费缓解焦虑 | 【道】 |

正例 01-04 + 09-10 最弱层大多是【道】——验证框架的核心论点：**大多数问题死在"图个啥"没想透**，下面四层补得再漂亮也救不回来。05-08 是边界样例：示范**什么时候不拆、怎么转**——知道不做什么，和知道怎么拆同样重要。

## 怎么看

每份样例都分三段：
1. **用户输入** — 模拟一个真实人的口语描述
2. **skill 回复** — 严格按现行格式展开（接住一句 → 总判定 → 道法术器势、势独立最后、每层一句 ✅/⚠️、末尾薄弱总结 + 今天的动作 + 回访钩子）
3. **示范了什么** — 给讲师/开发者看的拆解点（顺序锁死、薄弱不展开、指令带判定标准、主要矛盾唯一）

## 复刻 / 自测建议

- 拿样例里的"用户输入"覆盖成你自己的处境描述，直接喂给装好的 skill。
- 对比 skill 给你拆的结果和样例里拆的，看是不是同一套骨架——同骨架即格式稳。
- 如果某一层你拿不准，可以打开 `references/layer-{dao,fa,shu,qi,shi}.md` 看那层的标准动作库。
