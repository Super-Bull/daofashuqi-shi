# 实测样例 · AI爱好者想辞职做 OPC

> **模拟输入**（用户原话）：
> "我是一个AI爱好者，经常喜欢参加各种AI活动，自己也会用AI工具去做一些小应用，我想辞职了，上班太难受了，看不到未来，我想做OPC去赚钱，但是我不知道怎么才能有客户，比较纠结，老师能不能帮我分析一下？"

> **触发判定**：用户=OPC / 一人公司 / 超级个体 → 加载 `references/opc-playbook.md`。属"被势甩出来"那类（被上班逼出来的，自己没选过赛道）。未超转诊线（没投钱、没固定成本），3分钟自检范围内，硬跑。
> **格式锁**：接住一句 → 总判定 → 道→法→术→器→势，势独立最后；每层只一句✅/⚠️不展开；末尾薄弱点总结+今天的动作+回访钩子。

# 用「道法术器势」给你拆一遍

上班难受是真的，逃出来也是人之常情。但咱把话说前头：你现在还答不上来"辞职后第一个给你掏钱的人是谁"——最怕的是辞了之后才发现，躲进来的还是个空房间。

"为什么干"还没想清楚就准备辞——道层是"逃班"，"被谁需要"没想过。下面四层补得越漂亮、辞得越干脆，死得越快。

**总判定：先补【道】再谈**（写不出第一个掏钱的具体客户，绝对不许辞职）

1.▌道：（你图什么？·你的本心·初心）
- ✅：你真会动手用AI做小应用、真在跑AI活动，有技能底盘、有在场感。
- ⚠️：出发点停在"上班太难受、想逃"，"我给谁解决什么具体问题"还空着——"想做OPC去赚钱"是逃离在驱动。

2.▌法：（怎么做到？怎么赚钱？·商业逻辑）
- ✅：你已经能做出小应用，说明你真动了手。
- ⚠️：你连客户是谁都不知道（自己都说"不知道怎么有客户"），更没算过"一个客户净赚多少、获客花多少、有没有复购"——法层是空的。

3.▌术：（怎么获客？）
- ✅：你参加AI活动，这是现成的接近人的场景；会用AI工具做东西。
- ⚠️：你说"不知道怎么有客户"——术层完全没启动，只有"想做"、没有"下一步具体动作+截止日"。

4.▌器：（用什么工具？·工具）
- ✅：你会用AI工具，这是现成的器；小应用就是你的作品。
- ⚠️：作品、客户、流程全在你脑子里和微信里，没沉淀成可复用、可交接的资产，且高度依赖活动和平台场景。

──────────
（势是独立维度，不接在器之后、不在道法术器上下链里，下面单独看）

5.▌势：（现在是不是时候？·趋势·天时地利人和）
- ✅：AI现在火，你在场，有先发接触。
- ⚠️：你说"AI爱好者、参加活动"——这是公开共识（表层技术的势），不构成你的独占势；你答不出"为什么是现在、凭什么是你"，更答不出"企业从买岗位转向买结果"这个深层势，越干越像"又一个人学AI"。

# 薄弱点总结
最弱的是【道】：你是被上班逼出来的（自己没选过赛道），道层是"逃"，"被谁需要"没想过，所以法术器全悬空——不知道客户=术空，没算过赚钱=法空。道塌了，下面补得越漂亮死得越快。器也弱（没沉淀），但根在道。

# 今天的动作（聚焦道层，今天/本周就能做）
① 今天写下一句话："如果我现在辞职做OPC，第一个会掏钱给我的人是____（具体职业/场景），他正被____（具体问题）折磨，愿意付____元。"判定：写不出具体人/场景/金额 → 道没想透，绝对不许辞职。
② 这周去一次AI活动，不聊工具，专门问 3 个在场的人"你最近有什么事愿意花 500 块找人用AI帮你搞定"，记下来。判定：记到至少 1 个真实愿意付钱的具体需求。
③ 挑上面那个需求，用AI给他做一版最小demo发过去，问"你愿意付多少"。判定：拿到一个真实报价数字——"挺好""以后找你"都不算。

七天后来跟我说结果，我在。
